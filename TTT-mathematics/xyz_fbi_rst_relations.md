# XYZ・FBI・RST の関係式 — 6次元・9次元・27次元の整理（2026-10-17）

**位置づけ：** [`TTT_9dim_27dim_equations.md`](./TTT_9dim_27dim_equations.md) は考え始めた段階で記録した式で、直っていない部分がある。本書は、双極の中の **XYZ（位置）・FBI（力）・RST（回転）** の関係を式として固め直したものである。表記は 2026-10-05 の決定（回転3軸は RST、UVW は使わない）に従う。

**検証：** すべての定理は [`xyz_fbi_rst_check.py`](./xyz_fbi_rst_check.py) で機械検証済み（**18 PASS / 0 FAIL**、numpy のみ）。

本フォルダの方針に従い、物理単位は使わない。「力」「仕事」「トルク」は構造の名前として使う。

## 0. 旧記録との対応

| 旧記録 (`TTT_9dim_27dim_equations.md`) | 本書 | 扱い |
|:---|:---|:---|
| $U,V,W$（力学3軸） | $\mathbf F=(F,B,I)$ | 表記を FBI に統一 |
| $(\omega_x,\omega_y,\omega_z)$（回転） | $\mathbf R=(R,S,T)$ と、その時間変化 $\boldsymbol\omega=d\mathbf R/dt$ | 回転の向きを RST、速さを $\omega$ に分ける |
| $R,I,J$（精神3軸） | 本書では扱わない | 回転 RST と別物。文字 $i,j$ は四元数の虚数単位と衝突するため、本書の式には入れない |
| $\mathbf P_9=\pm2(\cdots)$ の $\pm2$ | 第3節の双極の差 | 係数の意味を式で定める |
| $\mathbf E_{27}=(\cdots)\otimes(\cdots)\otimes(\cdots)+(R,I,J)$ | 第4節 | 「27成分＋3成分」の足し算は定義されないため、3つ目の因子を RST にして閉じる |

### 旧記録で直す必要があった2点

1. **「27成分のテンソル ＋ 3成分」は定義されない。** 次元の違う量は足せない。
2. **9次元から27次元への矢印がつながっていなかった。** 9次元は3つの組の「和」（3＋3＋3）、27次元は「積」（3×3×3）である。9次元の3つの組をそのまま掛ければ、外に足す項は残らない。

## 1. 3つの組と、その間の3つの関係

$$\mathbf X=(x,y,z),\qquad \mathbf F=(F,B,I),\qquad \mathbf R=(R,S,T)$$

3つの組の関係は次の3つで閉じる。新しい文字は要らない。

| 関係 | 式 | 結果 |
|:---|:---|:---|
| 位置と力の内積 | $W=\mathbf X\cdot\mathbf F=xF+yB+zI$ | 数（仕事） |
| 位置と力の外積 | $\boldsymbol\tau=\mathbf X\times\mathbf F$ | 3成分（回転させる力＝トルク） |
| 回転が位置と力を回す | $\mathbf X' = q\,\mathbf X\,q^{*}$ | 四元数による回転 |

四元数は、回転軸の向き $\hat{\mathbf R}=(\hat R,\hat S,\hat T)$ と回転角 $\theta$ から作る：

$$q=\cos\frac{\theta}{2}+\sin\frac{\theta}{2}\,\bigl(\hat R\,i+\hat S\,j+\hat T\,k\bigr)$$

## 2. 6次元（核心）：位置＋回転

**状態：** $(\mathbf X,\mathbf R)\in\mathbb R^3\times\mathbb R^3$（1つのまとまりが持つ自由度。並進3＋回転3）

$$P_6=\mathbf F\cdot d\mathbf X+(\mathbf X\times\mathbf F)\cdot d\mathbf R$$

位置の変化には力が、回転の変化にはトルクが掛かる。回転と組む相手は位置と力から作れる（第1節）。

**定理1（回転の仕事）** 回転 $d\mathbf R$ による位置の変化は $d\mathbf X_{\rm rot}=d\mathbf R\times\mathbf X$ で、

$$\mathbf F\cdot(d\mathbf R\times\mathbf X)=(\mathbf X\times\mathbf F)\cdot d\mathbf R$$

したがって

$$P_6=\mathbf F\cdot\bigl(d\mathbf X+d\mathbf R\times\mathbf X\bigr)$$

すなわち **$P_6$ は「並進と回転を合わせた変位に力がした仕事」である。** 6つの項は別々の量ではなく、1つの力 $\mathbf F$ が並進と回転の両方に働いた結果として1本の式にまとまる。

この「6」は、立体が形を保つのに必要な辺の数 $3n-6$（[検証ノート 2026-10-17](#関連)）の6と同じもので、全体が丸ごと動く自由度を表す。

## 3. 9次元（完全状態）：3つの組を並べる

$$\Psi_9=(\mathbf X,\ \mathbf F,\ \mathbf R)\in\mathbb R^{9}\quad(9=3+3+3)$$

**定理5（双極の係数 ±2）** 双極ゼロ（00）の公理から、2つの極 $\Psi^{+}$, $\Psi^{-}$ の和は0：

$$\Psi^{+}+\Psi^{-}=0\quad\Longrightarrow\quad \Psi^{+}-\Psi^{-}=\pm2\,\Psi_9$$

旧記録の $\pm2$ は「全体に掛ける係数」ではなく、**2つの極の差**として現れる。符号は、どちらの極から見るかで決まる。

---

## 4. 27次元（創発・相互作用）：3つの組の積

$$T_{abc}=X_a\,F_b\,R_c\qquad(a,b,c=1,2,3),\qquad 27=3\times3\times3$$

旧記録で外に足されていた回転の組は、ここで3つ目の因子として中に入る。回転の速さ $\boldsymbol\omega$ は第5節の時間発展の側に移る。

**定理2（27成分の分解と唯一の不変量）**

1. 27成分は、回転に対して次の7つの部分に分かれる：
$$27=1+3+3+3+5+5+7$$
2. このうち回転させても値が変わらない成分は **ちょうど1つ** で、完全反対称な $\varepsilon_{abc}$ による
$$E_{27}^{(0)}=\varepsilon_{abc}\,X_aF_bR_c=(\mathbf X\times\mathbf F)\cdot\mathbf R$$
3. $E_{27}^{(0)}$ は **トルクが回転にした仕事** そのものである（第2節の $P_6$ の第2項と同じ形）。
4. $E_{27}^{(0)}$ は回転で不変、**鏡映で符号が反転** する。双極の ± が右回り・左回りに対応する成分は、27成分の中でこれ1つだけである。

各成分に ± を付ければ状態数は $2^{27}$ となり、創発階層図 $((2^3)^3)^3=2^{27}$ と一致する。

**位置づけ：** TTT の「ねじれの発生点」を式の中で指定するなら、候補は $E_{27}^{(0)}$ である（向きを持つ唯一の不変量であるため）。この同定は提案であり、未決定。

## 5. 時間発展（動的計算）

$$\frac{d^{2}\mathbf X}{dt^{2}}\propto\mathbf F,\qquad \frac{d\mathbf R}{dt}=\boldsymbol\omega,\qquad \frac{d\boldsymbol\omega}{dt}\propto\mathbf X\times\mathbf F$$

力が位置を変え、位置と力の外積が回転を変える。3つの組が一巡して閉じる。

比例係数（並進では質量、回転では慣性）の位置に、TTT の「加えられた力はエネルギーとして蓄えられる」という扱いが入る。係数の決め方は未定。

## 6. 60度の係数と四元数

**定理3** 平面の60度回転 $w=\dfrac{1+\sqrt3\,i}{2}$ の3次元版は

$$q=\frac{1+i+j+k}{2}$$

である。

| 性質 | $w$（平面） | $q$（立体） |
|:---|:---|:---|
| 実部 | $1/2$ | $1/2$ |
| 虚数部の大きさ | $\sqrt3/2$（$\sqrt3\,i$） | $\sqrt3/2$（$i+j+k$） |
| 6回で1に戻る | $w^6=1$ | $q^6=1$ |
| 回す角度 | 60° | **120°**（半角 60° の2倍） |
| 作用 | 正三角形・ハニカム | 頂点 $(1,1,1)$ を固定し、正四面体の残り3頂点を巡回 |

式に現れる「60度」は、正四面体を回す四元数の **半角** として現れている。空間で向きを扱うには四元数が要る、という立場（2026-09-25）とこの点で一致する。

## 7. 向きの符号と π（読み方の案・本人確認待ち）

旧記録の「$F\times B\times I=-1$, $FBI\pi=1$」（2026-10-05）、「$XYZ=-1$, $XYZ\pi=1$」（2026-10-11）は、次のように読むと式に入る。

- 3軸の組の向きを行列式で表す：右手系 $\det=+1$、左手系 $\det=-1$
- π を「向きを反転させる操作」とすると、$(-1)\times(-1)=+1$ で $XYZ\pi=1$, $FBI\pi=1$

**定理4** は行列式の符号とその反転を確かめたもので、π をこの役割に置くかどうかは **未決定**（TTT 内での π の意味——軸・内部運動エネルギー——との整合を確認する必要がある）。
