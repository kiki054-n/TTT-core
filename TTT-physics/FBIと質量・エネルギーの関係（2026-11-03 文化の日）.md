# OπO理論 — FBIと質量・エネルギーの関係

2026-11-03（文化の日） · 川上真潔 (Kawakami Naoyuki) · ORCID 0009-0009-2972-6511

2026-10-31「質と量・作用反作用・臍の緒のつながり」の続き。Claude との対話で、FBI（力・磁場・電流）の関係、質量を「質」と「量」に分ける考え方、質量欠損、光と長さの単位を一つの構図にまとめた。数値は電子質量 m_e を単位とする。判定は **正解／誤り／分からない** の三つで記す。

---

## 1. OOπO の発生（FBI の6点と原点）

OOπO は、双極の場の歪みで 00 点が生まれることから発生する。F に対応して B と I の点が双極で生まれ、点は **6点と原点**になる。

- F：原点の 0 からプラスとマイナスに離れては戻る**直線**の軌道
- B と I：F と直交する面を回る**曲線**の軌道。双極の場で二つの関係で動く
- 軌道は6つ

**検算**：B と I を互いに逆向きに回すと、外積から F の直線往復がそのまま出る。

$$\vec{I} = (\cos\omega t,\ \sin\omega t,\ 0), \qquad \vec{B} = (\cos\omega t,\ -\sin\omega t,\ 0)$$

$$\vec{F} = \vec{I} \times \vec{B} = (0,\ 0,\ -\sin 2\omega t)$$

- t = 0 で I と B は重なり、F は 0（00 点）。
- F は軸から外れず、B と I の回転の **2倍の速さ**で往復する。

---

## 2. 粒子の構造（3リングに閉じ込められた軸）

F の直線は B と I の回転を受けて回り、面をつくる。粒子は、B のリング・I のリング・倍の速さで動く F の面の **3リングに閉じ込められた軸**である。球（O）に囲まれた双極子（OπO）として表す。

- 互いに直交する3つの大円は **6点**で交わり（正八面体の頂点）、球面を **8枚**の三角形に分ける。
- 重なった2つのエネルギーが速度 0 から光速に至って励起した状態で、エネルギーは **2F＋I＋B**。光速ではエネルギーが振動数に比例するので、倍の振動数の F は 2、合計 4 単位。
- 粒子条件は外郭と3要素。3要素が双極子。
- リングは光速で回るので重さ 0、量 0。軸の単振動も量 0。質のエネルギーは存在する。
- B と I は逆向きに回るので、角運動量は打ち消し合う。

参考（相対論）：質量 0 のものどうしでも、逆向きに動いて閉じ込められると、系全体は静止質量 M ＝ E_合計 / c² を持つ。

## 3. 質と量の分離

質量は「質」と「量」の和である。質だけのもの、量だけのもの、両方を持つものがある。

| もの | 要素数 | 質 | 量 | 質量（m_e） |
|---|---|---|---|---|
| 空間の OπO | 3 | 3 | 0 | 1/500（約 1.02 keV） |
| 電子（外郭の O 500個） | 500 | 500 | 0 | 1 |
| 格子線1本（F） | — | 0 | あり | 2.44420356 |
| 陽子（OπO 4×3×125） | 1500 | 1500 | 格子線 750本 | 1836.15267343 |

- OOπO 粒子 500個 ＝ 外郭の O 500（電子）＋ OπO 500（1500要素、陽子）。要素数の合計は 2000。
- 陽子はテトラ：頂点4つにそれぞれ OπO 125個、辺6本にそれぞれ 125本で、格子線 750本。
- 陽子の質の分は電子3個ぶん。残りが格子線に蓄えた量。
- 格子線は F であり体積を持たない。両側に引き合う力は中和して 0 に見えるが、質量はある。**質 0 で量だけがある**。

格子線1本あたりの質量：

$$\frac{1836.15267343 - 3}{750} = 2.44420356\ m_e = 1.24899\ \text{MeV} = 2.22652 \times 10^{-30}\ \text{kg}$$

## 4. F＝ma と空間

F＝ma の質量には、加速度がかからないものと、かかるものがある。空間には加速度を与えられない。**力では動かないのが空間である。**

- 空間の質：粒子になっていない。力では動かない。
- 粒子になった質：エネルギーに換わり、加速できる（電子の質量）。
- 粒子の中の量：格子線の力として、加速できる（陽子の質量の大半）。

加速できるかどうかを決めるのは、質か量かではなく、**粒子になっているかどうか**である。

## 5. 臍と臍の緒

電子の雲は、陽子の外郭と臍でつながっている。臍と臍の緒は空間1単位の OπO（要素3）である。

| 状態 | 電子 | 臍の緒 | 陽子 | 合計 |
|---|---|---|---|---|
| 水素原子（つながっている） | O 500 | OπO 3 | 1500 | 2003 |
| 切れた後（電離） | O 501 | — | 1500 ＋ ねじれた Oπ 2（極） | 2003 |

- 臍の緒が切れると、O が電子に付いて 501 になる。ねじれた Oπ は陽子外膜の極になる。
- 要素は保存される。水素原子と「陽子＋電子」の質量差 13.6 eV は、臍の緒の張力（量）と読める。
- 水素原子は空間1を使う。水素分子は臍の緒2本で空間2、質6。
- 空間はどこにでも同じように満ちているので、借りた1単位は差としては質量に現れない（比重で数える）。

## 6. 質量欠損

質量欠損は質と量の計算である。**要素（質）の欠損も、空間の欠損もない。エネルギーの総和は変わらない。** 減るのは閉じ込められた量で、減った分と同じだけが光・ニュートリノ・運動として外に出る。

### 6.1 数の帳簿

中性子を「陽子 1500 ＋ 電子 500」と数える。

| 反応 | 前の要素 | 後の要素 | 消える質量（実測） |
|---|---|---|---|
| 中性子 → 陽子＋電子 | 2000 | 2000 | 0.78 MeV |
| 陽子＋中性子 → 重水素核 | 3500 | 3500 | 2.22 MeV |
| 重水素核2個 → ヘリウム4核 | 7000 | 7000 | 23.85 MeV |
| 水素原子4個 → ヘリウム原子 | 8000 | 8000 | 26.7 MeV |
| 水素原子 → 陽子＋電子 | 2003 | 2003 | 13.6 eV |
| 水素原子2個 → 水素分子 | 空間 1＋1 | 空間 2 | 4.48 eV |

- ヘリウム ＝ 陽子2＋中性子2＋電子2 ＝ 8000。原子核は 7000。
- 重さは直接量られている（ペニングトラップ）。水素原子 1.00782503 u × 4 ＝ 4.03130 u、ヘリウム4原子 4.00260325 u。差 0.0287 u ＝ 26.7 MeV。

| | 閉じ込められたエネルギー | 外に出たエネルギー | 合計 |
|---|---|---|---|
| 水素原子4個 | 4.03130 u | 0 | 4.03130 u |
| ヘリウム4＋放出 | 4.00260 u | 0.02870 u | 4.03130 u |

### 6.2 欠損は F の中和エネルギー

欠損は F の中和エネルギーと読む。エネルギーは力の大きさそのものではなく **力 × 動いた距離**である。引き合う力が働いたまま粒子が近づくと、その仕事がエネルギーとして外に出る。中和し終わると F は 0 に見えるが、出たエネルギーは戻らない。

- 水素分子：陽子の膜はそれぞれ別のまま。空間は 2 のまま。欠損は 4.48 eV だけ。
- ヘリウム：4粒子が1つの膜を共有する。欠損は MeV の桁。

格子線1本（2.444 m_e）で割った換算：

| | 欠損 | 本数に換算 | 格子線の総数に対する割合 |
|---|---|---|---|
| 重水素（2粒子） | 4.353 m_e | 1.78本 | 1500本の 0.12% |
| ヘリウム4（4粒子） | 55.373 m_e | 22.66本 | 3000本の 0.76% |
| 重水素2個 → ヘリウム4 | 46.67 m_e | 19.08本 | — |

- 中和するのは格子線全体の 1% 足らず。テトラの構造の 99% 以上はそのまま残る。
- ヘリウム ÷ 重水素 ＝ 12.72。1本の力が一定なら中和した本数の比は整数比になるはずだが、小さな整数比にならない。一部だけ中和する線があるか、整数で割り切れない端数（臍）が各核に残るか、のどちらかが必要。
- 参考：原子核の中の核子は、中のクォーク分布が外にいるときと異なる（EMC効果、1983年）。結合エネルギーのうち「核子の中の変化」と「核子どうしの力」は一通りには分けられない。

### 6.3 太陽

太陽は軽くなっている。光として毎秒約 426万トン、太陽風として毎秒約 100万〜200万トン。46億年で全体の約 0.04%。誕生時より明るさは約30%増え、半径も1割ほど大きくなったとされる。**質を持ったまま、蓄えた量を放出している。**

- 太陽の中の水素はプラズマで、陽子と電子にばらばら（臍の緒が切れた状態）。
- 陽子2個が中性子に変わるとき陽電子とニュートリノが出る。陽電子は電子と出会って光になる。消えた電子2個は中性子の中に入った形になり、8000 の帳簿が閉じる。

## 7. 光と長さの単位

**光は空間の格子線の移動、つながった空間の振動、エネルギーの移動である。** 光は新しい要素ではない。核融合は「格子に閉じ込められた量が、空間の格子線の振動として膜の外へ出る」と書ける。

- OπO より短い波長は存在しない。
- OπO のリングの半径は限りなく 0 に近い 1。π は限りなく短い線。つながっていて速さは光速で、光速を超えられない。
- **長さの単位は無次元単位**である。

### 7.1 観測との関係

- 観測された最短の光：LHAASO の約 1.4 PeV ガンマ線（2021年）、波長約 8.9 × 10⁻²² m。OπO はこれより小さい。無次元で限りなく小さいなら矛盾しない。
- フェルミ衛星 GRB 090510（2009年）：エネルギーが100万倍違う光がほぼ同時に到着。格子があってもその間隔はプランク長さ程度以下。限りなく小さい OπO と矛盾しない。
- 空間そのものは直接観測できない。1メートルは光速から、1秒はセシウム原子の振動から定義されている。長さは空間の中のものの比で決まる。重力波の観測も、空間の伸び縮みの割合（無次元、約 10⁻²¹）。
- 物理学でも、単位に左右されない本当の定数は無次元の比だけ（α、陽子／電子質量比）。TTT が要素の数と比で 1836.15 を出そうとするのは、この種類の主張である。

### 7.2 FBI と α

フレミングの FBI の強さを決める真空の透磁率には、2019年の SI 改定で微細構造定数が直接入った。

$$\mu_0 = \frac{2\alpha h}{e^2 c}$$

- 平行電流の力：F / L ＝ μ₀ I₁ I₂ /(2π d)
- 直線電流のまわりの磁場：B ＝ μ₀ I /(2π r)（直線の I のまわりに輪の B）
- 輪電流の中心の磁場：B ＝ μ₀ I /(2R)（輪の I の中心に直線の B）
- 直線と輪が入れ替わる関係を双極で閉じた形が、B・I の2リングと軸の F の構図と読める。

試算：FBIπ ＝ 1、2F ＝ BI からは F ＝ 1/√(2π) ＝ 0.39894、BI ＝ 0.79788 が決まるが、α（1/137.036）は出ない。α を出すには、電荷 e（格子線の力）、ħ（光速リングの回転の最小単位）、c（リングの速さ）を結ぶ式がもう一つ要る。

$$\alpha = \frac{e^2}{4\pi\varepsilon_0 \hbar c}$$

### 7.3 粒子数と辺の長さ

立方体に並べた粒子の1辺の数は粒子数の3乗根。アボガドロ数 6.02214076 × 10²³ の3乗根は 8.4446 × 10⁷。

| | 1モルの立方体の1辺 | 粒子の間隔 |
|---|---|---|
| 気体（0°C、1気圧、22.414 L） | 28.19 cm | 3.34 nm |
| ケイ素の結晶（12.06 cm³） | 2.293 cm | 0.2716 nm（格子定数 543.10 pm の半分） |

1 → 8 → 27 → 64 → 125 と同じ規則。メートルで辺を決めるには粒子の間隔を別に測る必要があり、数だけでは比しか決まらない。

## 8. 判定

| 項目 | 判定 | 根拠 |
|---|---|---|
| B と I の逆回転から F の直線往復が出る | 正解 | 外積の計算（1節） |
| 光速リングは量 0 でもエネルギーを持つ | 正解 | 光子は静止質量 0 で E ＝ pc |
| 釣り合った力（格子線）に質量がある | 正解 | 蓄えたエネルギー E/c² は慣性と重力に現れる |
| 反応の前後で要素（質）が保存される | 正解 | 6.1節の帳簿がすべて閉じる |
| 質量欠損でエネルギーの総和が増える | 誤り | 総和は不変。閉じ込められた分が外へ出るだけ |
| 欠損は F の中和エネルギー | 分からない | 方向は物理学と合う。1本の値を一定にすると比 12.72 が整数比にならない |
| 空間は力で動かない | 正解 | 空間に対する速度は測れない（相対論） |
| 長さは無次元単位 | 分からない | 矛盾はないが、空間の質量を観測密度と比べるにはメートル換算が一つ要る |
| FBIπ＝1、2F＝BI から α が出る | 誤り | 未知数が足りず、137 が現れない |
