# OπO理論 — 検証記録と予言の形

2026-09-19 · 川上真潔 (Kawakami Naoyuki) · ORCID 0009-0009-2972-6511

## 方法 — 単位を決めずに展開する

長さ・質量・時間の単位も、力・磁界・電界の単位も固定せずに理論を展開する方針を採る。

これはバッキンガムの Π 定理に支えられる。n 個の変数と k 個の基本次元があれば、関係式は n−k 個の無次元量だけで書ける。Π 定理が保証するのは「次元的に整合した法則を無次元量の関係に書き換えられる」ことであって、無次元量でない物理量が実在しないという意味ではない。したがって本記録では、**単位系に依存しない比較と予言を行うため、無次元量を基本的な検証対象とする方針**である。

方針と成果は一致している。本記録に現れる重要な数はすべて無次元である。

- γ − 1（PPN パラメータのずれ）
- a/l_P（格子間隔とプランク長の比）
- η = 6.1×10⁻¹⁰（バリオン非対称）
- 境界 : 軌道 = 1 : 3
- 光の曲がりの係数 4、測地歳差の係数 3/2

### T の定義

出発から誕生まで、すなわち光速の限界に達するまでの期間を T と置く。

そのままでは定義できない。無質量のものは常に c なので T = 0、質量を持つものは c に漸近するのみで T = ∞ となる。加速度を指定すれば決まる。プランク加速度を取ると

    a_P = √(c⁷/ℏG) = 5.561×10⁵¹ m/s²,   c/a_P = 5.3912×10⁻⁴⁴ s = t_P

プランク時間と厳密に一致する（誤差 10⁻¹⁶、丸めの範囲）。

ただし論文に書く順序は逆にすべきである。「〜するまでの経過期間」で時間を定義するには、その経過を測る時計が要り、時計は時間を前提とするため循環する。t_P = √(ℏG/c⁵) は定数だけから決まり、どの過程にも依存しない。**次元解析で定義し、「プランク加速度で 0 → c に要する時間でもある」を解釈として添える**のが安全である。

### T とエネルギー

    ΔE · Δt ≥ ℏ/2  ⟹  E ∼ ℏ/t

時間の単位を決めると、対応するエネルギーが決まる。ただし下表の読み方には注意が必要である。陽子と電子の行は t = ℏ/(mc²) をコンプトン時間として選んでいるため、E = ℏ/t から mc² が出るのは恒等式であって導出ではない（検算で確認済み）。独立なのはプランクの行だけで、t_P は G から定義され mc² とは無関係である。また ΔE·Δt ≥ ℏ/2 は不等式であり、E = ℏ/t というエネルギー生成則を直ちに意味しない。現段階ではこの表は「既知の質量‐エネルギー関係を時間尺度で書き直したもの」と分類するのが正確である。

| スケール | 時間 t | E = ℏ/t |
|---|---|---|
| プランク時間 | 5.4×10⁻⁴⁴ s | 1.2×10²⁸ eV |
| 陽子 ℏ/(m_p c²) | 7.0×10⁻²⁵ s | 9.4×10⁸ eV |
| 電子 ℏ/(m_e c²) | 1.3×10⁻²¹ s | 5.1×10⁵ eV |
| ハッブル時間 1/H₀ | 4.6×10¹⁷ s | 1.4×10⁻³³ eV |

電子の行とツィッターベーヴェグングの関係は π 倍ずれる。ω_Z = 2mc²/ℏ なので周期は T_Z = 2π/ω_Z = πℏ/(mc²) = 4.047×10⁻²¹ s、一方コンプトン時間は ℏ/(mc²) = 1.288×10⁻²¹ s で、比はちょうど π（検算済み）。「一致」ではなく「同じ質量尺度から得られる二つの特徴時間」が正しい。両極端の比は

    t_P/t_H = 1.18×10⁻⁶¹,  (t_P/t_H)² = 1.39×10⁻¹²²

これは宇宙定数問題の桁と一致する（後述）。

## 構成の鎖

出発点から現在までの導出経路。各段は後続の節で検証結果を示す。

### 幾何の鎖

双極零 → 分離面 → 双錐（Z₂）→ OOO（C₃）→ 三角双錐（D₃ₕ）→ 立方配列

1. **双極零** — 0次元の点に内部自由度を持たせる形。リーマン球面では 0 と ∞ が二極、z → 1/z が対合
2. **分離面** — 極の比が 1 なら平面、2:1 なら球（アポロニウス球）
3. **双錐** — SO(3) が SO(2)×Z₂ に破れる。球は排除される
4. **OOO** — 3つのリングが C₃ を要求し、[111] 軸が立つ
5. **三角双錐** — 頂点 5 = 双極 2 + OOO 3。対称群 D₃ₕ（3軸3面）
6. **立方配列** — OπO の中心が作る格子。異方性は l=4 から

### 代数の鎖

OOO + 1 = 四元数 → S³ → SO(3)（2:1 被覆）

幾何の 2π = 代数の π。この比 2 が被覆度そのものである。「線から立体を作る定義」はここにある — リー環（双ベクトル、平ら）を指数写像でリー群（S³、曲がった立体）にする操作。

### 物理の鎖

π 周期 = スピン2 → トレース反転 → h₀₀ = h_ij → γ = 1 → 光の曲がり 1.75″

**この鎖が現時点で最も強い。** π という記号が、因子2を出すために必要な性質（π 周期 = スピン2）を、名前の時点で持っていた。

ただし正確に言えば、これは「理論から導かれた」ではなく「必要な性質を最初から名乗っていた」である。π が 180° で閉じ、矢印にならず、源に Z₂ 的に結合することを定義から言えるようにすれば、γ = 1 は仮定ではなく定理になる。

## 確立した対応（幾何・代数）

すべて計算で確認済み。ただし**これらは既存の数学との一致であり、新規の定理ではない**。

### 零と無限

実数では 1/0 は未定義。リーマン球面（拡張複素平面）では 1/0 = ∞ が定義され、f(z) = 1/z は f(f(z)) = z で対合。立体射影で 0 が南極、∞ が北極。双極零の数学的な住所はここにある。

0/0 は不定形で、近づき方で答えが変わる（sin x/x → 1、x²/x → 0、x/x³ → ∞、ax/x → a）。ただしこれは量子測定ではなく**経路依存**である。区別して書くこと。

### 分離面

極を z = ±d、強さの比を 2:1 とすると、φ = 0 の軌跡は

    x² + y² + (z + 5d/3)² = (4d/3)²

中心 z = −5d/3、半径 4d/3 の球面。弱い極を包み、強い極は外側。比が 1 のときだけ平面になる。平面は一般形ではなく**縮退した臨界の場合**である。

### 双錐

- V − E + F = 2、連結成分 1（格子で 16681 点を数えて確認）
- 赤道面の鏡映 σ で双錐/Z₂ = 単錐。**双錐は単錐の二重被覆**
- 曲率の特異集合は 2頂点 + 赤道円 = 構成した 3 つの対象と一致
- 各頂点の角欠損 2π(1 − a/L)、赤道 4πa/L、合計 4π（ガウス・ボネ）
- 慣性等方となるのは a/h = √(2/3) = 0.8165 のときのみ

### OO と OOO

逆回転する 2 円の和は厳密に直線振動になる。

    L_total = 0,  E_total = (1/4)mA²ω² ≠ 0

**平均は零、分散は非零。** 回転反転 σ は対合で、OO は σ 固定点、O は符号を担う。状態数は 2 + 1 = 3 = 2l+1（l=1 三重項）。

C₃ については訂正がある（次節）。3つのリングの角運動量和がゼロになるのは、**法線が [111] 軸に垂直な場合のみ**。座標平面に置くと和は √3 L で軸方向を向く。

### Cl(3)

次元内訳 1 + 3 + 3 + 1 = 8。

    B = e₁₂ + e₂₃ + e₃₁,  B² = −3,  B̂ = B/√3,  B̂² = −1
    R = ½(1 − e₁₂ − e₂₃ − e₃₁) が C₃ を厳密に再現（R e₁ R̃ = e₂ 等）

擬スカラー e₁₂₃ は不変。**3つのリングの和が、規格化すると虚数単位になり、それ自体で1本の回転軸の生成子になる。**「リングが3つ、回転軸が1つ」は Cl(3) の中の等式である。

XYZ と OOO はホッジ双対（I e₁ = e₂₃ 等）。ただし I² = −1 なので対合ではなく **Z₄**（軸 → 面 → −軸 → −面 → 軸）。前出の Z₂ とは別種の対である。

### 四元数と S³

偶部分 {1, e₂₃, e₃₁, e₁₂} は次元 4、i² = j² = k² = ijk = −1 でハミルトンの四元数と同型。単位四元数の集合は S³。

SU(2) → SO(3) が 2:1。ローターは半角なので、**幾何の 2π が代数の π に対応する**。この 2 が被覆度である。

### 多面体

- 5 = 2 + 3 = 三角双錐の頂点（V=5, E=9, F=6）。D₃ₕ は位数 12、C₂ 軸 3本、σ_v 面 3枚
- D₅ₕ は C₂ 軸 5本、σ_v 面 5枚。ただし **n 軸 n 面は全 D_nₕ で成立**するので、5 の特別さは示せない
- 軸と面の対応は**包含**（σ_v が C₂ を含む）であり、ホッジ双対（直交）とは別物
- 正三角形面の双錐は n < 6 から n = 3, 4, 5 のみ → 7 = 5 + 3 − 1（正八面体が重なる）
- 自己双対な族は角錐（V = F = n+1）。V = F = 5 は四角錐のみで、頂点が 1 つしかなく双極構造を失う
- I_h（位数120）は D₃ₕ と D₅ₕ を共に部分群に持つ。5回軸 6本、3回軸 10本、2回軸 15本
- 内接関係の数は群の指数から出る：|O|/|T| = 2、|I|/|T| = 5、|I|/|D₃| = 10

## 確立した対応（物理）

### スピン2 と γ = 1 — 現時点で最も強い鎖

弱場の計量を時間側 α、空間側 β に分けると、実効屈折率は n = 1 + (α+β)GM/(rc²) となり、**和 (α+β) だけで決まる**。曲がり角は α_defl = 2(α+β)GM/(bc²)。

| 配分 | α+β | 曲がり角 |
|---|---|---|
| 時間のみ | 1 | 0.876″ |
| 空間のみ | 1 | 0.876″ |
| 等分（GR） | 2 | **1.752″** |

観測 1.750″（VLBI、精度 0.02%）。**どちらか一方に寄せると半分になる。**

α = β を強制するのは質量ゼロの**スピン2**である。調和ゲージで h̄₀₀ = 4Φ/c²、他はゼロ。トレース反転 h = h̄ − ½η h̄ を施すと h₀₀ = h_ij = 2Φ/c²。**完全に等しくなる。** トレース反転項が源を時間と空間に等分配するため。スカラー成分を混ぜると γ が 1 からずれ、Cassini の γ − 1 = (2.1 ± 2.3)×10⁻⁵ から ε < 10⁻⁵。

そしてスピン2 とは **π 周期**のことである（偏光の間隔 90/s 度、s=2 で 45 度、周期 180 度 = π）。重力波の 2 偏光が 45° ずれているのが観測的な証拠。

### 測地歳差

GP-B 軌道（r = 7013 km）で導出すると 6637 ミリ秒角/年。測定値 6601.8 ± 18.3 との差 0.5%。単位長さあたりに直すと閉じた形になる。

    dθ/ds = (3/2) g/c² = 1.3525×10⁻¹⁶ rad/m（厳密一致）

特徴的な長さ c²/g = 1.17 光年。**重力に直交して 1.17 光年進むと向きが約 1 ラジアン回る。**

OπO がプランク長ごとに 1 個なら、1 個あたりの回転は (3/2)g l_P/c² = 2.19×10⁻⁵¹ rad。重力は膨大な数の極微の向きのずれの累積になる。これは重力が他の力より 10³⁶ 倍弱いことと無理なく繋がる。

フレームドラッギングは GJ/(2c²r³) ≈ 41 ミリ秒角/年（測定 37.2 ± 7.2）。測地歳差との比 162:1。

### 存在と運動

Δx·Δp ≥ ℏ/2 により、Δx = 0 かつ Δp = 0 の状態は**ヒルベルト空間に存在しない**。「止まったら存在が消える」の厳密形。

- 陽子質量 938.27 MeV に対し、クォーク3個の静止質量は 8.99 MeV（0.96%）。**99% が内部運動と場**
- ヘリウムは 1 気圧では絶対零度でも固化しない（固化に約 25 気圧）
- 調和振動子の基底状態 E₀ = ℏω/2 ≠ 0

### 質量の起源

M²c⁴ = (ΣE)² − (Σpc)² より、逆向きに進む光子 2 個は M = 2E/c² ≠ 0。**質量ゼロの粒子だけでできた系が質量を持つ。** 条件は正味の運動量がゼロ、つまり閉じ込められていること。これは OO（L=0, E≠0）と同型。

ディラック方程式で電子の速度演算子 cα の固有値は ±c のみ。観測される v < c は時間平均（ツィッターベーヴェグング、ω_Z = 1.55×10²¹ rad/s、振幅 = 換算コンプトン波長 3.86×10⁻¹³ m）。

ただし機構は陽子と電子で異なる。陽子は複合粒子で内部運動、電子は素粒子でヒッグス湯川結合（y_e = 2.94×10⁻⁶、複合性の上限 10⁻¹⁸ m）。「電子の質量の起源は閉じ込めである」は標準模型と競合する仮説であり、明白な誤りではない。

### 宇宙

- 総和 0：Ω_total = 1.0000 ± 0.0018。これは空間的にほぼ平坦であることの観測であり、**ここから「全エネルギー = 0」は導けない。** 曲率パラメータの値と「正エネルギー＋負の重力エネルギー = 0」は別の命題である。ゼロエネルギー宇宙（Tryon 1973）は示唆的な対応だが、平坦性から証明されるものではない
- 物質のエネルギー +2.7×10⁷¹ J、重力の位置エネルギー −8.4×10⁷¹ J（同桁で逆符号）
- 局所的には ∇_μ T^μν = 0 が成立する。一方、膨張宇宙には時間並進対称性がないため、ネーターの定理に対応する**大域的な総エネルギー保存量を一般には定義できない**
- 輻射は a⁻¹ で減少、物質は一定、ダークエネルギーは a³ で増加。共動体積内で**34億年ごとに倍増**
- これは OO と同型：各項は増え続けるが総和は 0 のまま
- バリオン非対称 η = 6.1×10⁻¹⁰ はゼロでない。**この残差が物質の存在理由**

### 面積則と境界

体積則では合わず、面積則で観測値が出る。

    ρ = ρ_Planck (l_P/R_H)² = 7.1×10⁻²⁶ kg/m³（観測 6.0×10⁻²⁷、ずれ約12倍）

10¹²³ の食い違いが 10¹ まで縮む。体積則 (l_P/R_H)³ では 8×10⁻⁸⁷ で小さすぎる。**抑制は体積ではなく面積で効いている。**

同じ面積則が Jacobson (1995) の創発重力の核にある：S = A/(4l_P²)。局所地平面に δQ = T dS を課すだけでアインシュタイン方程式が出る。境界形成エネルギー → 面積則 → ホログラフィー → 創発重力の鎖は、既存の物理の中で繋がっている。

バッグ模型の構造から、平衡での比が確定する。**境界 : 軌道 = 1 : 3**（R にも B にも N にも依らない）。四つのエネルギーのうち独立なのは 2 つ（空間エネルギー密度 B と軌道エネルギー）。境界 = B × 体積、質量 = 両者の和、はいずれも従属。

### 誕生則と上限

数列は後節「立方拘束の再構成」で 1, 6, 18, 54, 162 に訂正されている（n=1 で立方拘束 1³ と完全一致するため）。以下の上限の議論は増殖率 3 のみに依存するので、どちらの始め方でも変わらない。増殖率 3 = OOO の個数。

c が限界速度なら、事象の地平線が飽和する（R_dS = c/H₀ = 1.373×10²⁶ m）。

    3ⁿ ≤ A/(4l_P²) = 2.27×10¹²² ⟹ n_max = 256

Δt に依らず、H₀ の不確かさにも頑健（67.4 と 73 で 256.4 → 256.2）。成長は止まらず、世代が尽きる。

※ 256 = 2⁸ は偶然の可能性が高い。log を取った結果の数で、定数がわずかに違えば 255 や 257 になる。押さないこと。

### 用語上の注意

- OO の「零」は**角運動量の零**であって、エネルギーは零でない。論文では L = 0, E ≠ 0 と明示する
- 「エネルギーが増える」は保存則違反ではない。**破るべき保存則がそもそも存在しない**（ネーター）。論文はここから書き始めること
- 「多くの 1」の同一視に注意。境界の 1、誕生の出口の 1、価電子の 1、中性子の 1、余りの 1 — 少なくとも 1 つ（中性子）は別物と判明した。それぞれ別の名前と定義を与え、同一性は等号として証明すること

### 位相相殺ではエネルギーは消せない

120° ずつずれた 3 つの寄与について、1次量は完全に消えるが 2次量は消えない。

    Σ cos(θ + 2πk/3) = 0,  Σ cos²(θ + 2πk/3) = 3/2,  Σ|A_k|² = 3（位相に依らない）

**エネルギーは 2 次量で正定値。** 各項が正なので和がゼロになりようがない。n 重にしても同じ。したがって OOO の位相配置から宇宙定数の抑制を出す道は閉じている。厳密な相殺として知られるのは超対称性のみ。必要なのは位相ではなく**符号**である。

### 四面体の頂点楔積和は不変量でない

Σ_{i<j} a_i ∧ a_j は頂点のラベル付けで値が変わる（24 通りの並べ替えを総当たりして ±4e₁₂, ±4e₂₃, ±4e₃₁ の 6 通り）。ラベル依存の量は幾何学的不変量ではない。

### 6 成分の四元数は存在しない

フロベニウスの定理（1877）：実数体上の有限次元・結合的な可除代数は R(1), C(2), H(4) のみ。フルヴィッツ：ノルム可除代数は 1, 2, 4, 8 のみ。**6 はどちらにも現れない。**

P = xX + yY + zZ + rR + iI + jJ が指す対象は実在するが、それは 4 次元の双ベクトル（= so(3,1) の元 = 電磁場テンソル F_μν）である。housing する代数は**複四元数** = Cl⁺(1,3) ≅ Cl(3)、次元 8（1 + 6 + 1）。

### 対称性の非両立

- **D₃ₕ ⊄ O_ₕ**。O_ₕ（位数48、符号付き置換行列）を全列挙して確認。[111] 軸まわりの C₃ は含まれるが、[111] に垂直な鏡映面は含まれない（行列成分が ±1/3, ±2/3 で非整数）。O_ₕ が [111] に持つのは S₆ であって S₃
- **5 回対称は周期格子に入らない**。2cos(2π/5) = (√5−1)/2 = 0.618 が非整数（結晶学的制限定理）。周期格子が許すのは 1, 2, 3, 4, 6 回のみ。5 回対称が実在する唯一の形は準結晶（非周期）

### Δt = t_P の世代成長は破綻する

N(t) = 3^(t/Δt) − 1 で Δt = t_P とすると、n = 254（t = 1.4×10⁻⁴¹ s）でホログラフィック限界 1.8×10¹²¹ を、n = 383 でプランク体積数 6.1×10¹⁸² を突破する。現在までの世代数は 8.1×10⁶⁰ で意味をなさない。

※ 「世代」には両立しない 2 つの意味があった。(A) 成長則の反復（同質・等間隔）と (B) 宇宙のエポック（異質・不等間隔）。エポックの間隔は 9, 23, 6, 7, 11 桁とばらばらで、等比数列にはならない。**時間軸から外して「構造の階層」として読めば、Δt を決める必要がなくなる。**

### 落下の慣性説明 — 4 つの独立な反証

「リンゴは慣性で落ちる／ジャイロ効果で動く」は、以下のいずれによっても成立しない。

1. **赤道と極の g の差** — 自転速度が最大の赤道で 9.780、ゼロの極で 9.832。慣性が原因なら逆になるはず
2. **奇数列と重心定理** — 等時間間隔の落下距離は 1:3:5:7:9:11（等加速度の署名）。速度一定なら 1:1:1:1。また内部の力はすべて対消滅するので、重心は内部運動では加速しない
3. **磁化** — 磁化 M = Br/μ₀ = 1.15×10⁶ A/m は「双極子の向き × 数」そのもの。10²⁸ 個/m³ が揃っても磁石は動かない。向きの蓄積が生むのは**場**（J_b = ∇×M）であって運動ではない
4. **ホロノミー** — 「ベクトルを失わない」＝曲率ゼロ＝重力なし。GP-B は 0.3% の精度で失われることを測定した（6601.8 ± 18.3 ミリ秒角/年）

さらに、向きは物体に固定された量、速度は観測者依存の量。**静止系では v = 0、別の系では v ≠ 0、しかし向きは同じ。** 論理的に向きが速度を決めることはできない。「OπO の空間を移動する」は絶対空間を要求し、Δc/c < 10⁻¹⁸ と衝突する。**「位置ではなく向きが変わる」という定式化を維持すること。**

### 生きているという比喩

星の世代による元素の継承は実在する（Z = 0 → 0.014）。しかし複製・変異・選択の三つが揃わなければ進化にならない。機構を書けば科学になる前例はある（Smolin 1992 の宇宙論的自然選択）。ただし星形成率は z ≈ 2 でピークを過ぎ、現在は 1/10 に低下している。

## 唯一の予言候補

### 前提の指定

- **(a) 格子** — OπO の中心は単純立方配列を作る。距離を持つ 2 面、面の距離を置く 4 本の線
- **(b) 応答** — 質量に反応して回転角が変わり、回転の歪みで線の長さが歪む。隣接して立方の組み合わせが成立する

### 構造的に有利な点 — 1 次の項が存在しない

格子間隔 a の離散構造では分散関係が

    ω = (2c/a) sin(ka/2) = ck[1 − (ka)²/24 + …]

より一般に、反転対称性を持つ格子では動力学行列が D(k) = D(−k) となり ω²(k) が k の偶関数になるため、位相速度の補正は偶数冪のみになる（最近接単純立方に限らない）。ここでは sin が奇関数であることから直接、**偶数次しか出ない。1 次の項が構造的に存在しない。**

GRB 090510（Fermi/LAT、31 GeV 光子の到達時間差）は**1 次のローレンツ破れを E_QG,1 > 1.2 E_Planck で既に排除している。** 格子構造はこの制約を自動的に回避する。
