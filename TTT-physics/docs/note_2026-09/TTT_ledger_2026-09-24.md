## 5. 提案された「TTT 定量的モデル」への判定

> Q_meas(B) = Q_sp(B) + Q_core(B)
> ① 幾何学は「舞台」：Goldberg ベクトル (h,k) が魔法数 B を決定し、核の安定性を支配
> ② 最後の核子は「演技者」：軌道（n, l, j）が single-particle 効果を決定
> ③ 核心分極は「集団効果」：single-particle 効果を上回り、変形の符号と大きさを支配

| 項目 | 判定 | 理由 |
|---|---|---|
| 式 Q_meas = Q_sp + Q_core | ○【既知】 | 殻模型の標準的な分解。ただし TTT 固有の内容はまだ入っていない |
| ① | **✗** | (h,k) が決めるのは「無質量パイ中間子・有理写像近似でのスカーミオンのエネルギー」の予想列。実在核の安定性とは結びついていない（4-4）。しかも正二十面体対称では Q = 0（A6）なので、幾何は Q に寄与しない |
| ② | ○【既知】 | 殻模型そのもの（B8） |
| ③ | **✗（修正して○）** | 核心分極は **符号を変えない**。符号は「粒子か穴か」で決まり 6/6 一致。核心分極は重い核で大きさを 2〜4 倍に増強する（B9） |

**修正版（この形なら実測と整合する）**

- Q_sp(n, j) = −(2j−1)/(2j+2)·⟨r²⟩·(2j+1−2n)/(2j−1)·e_eff … 符号は n/(2j+1) が 1/2 未満か超えるかで決まる
- Q_core は Q_sp と同符号で、閉殻から遠い核ほど大きい
- **幾何学（二十面体殻）は、このモデルのどの項にも入らない。** これは 1949 年以来の殻模型であり、TTT のモデルと呼ぶには TTT 由来の量を 1 つ以上含める必要がある

## 6. 次に進むなら（TTT 固有の予言を立てる候補）

1. **C1：磁束 n = 3 の出所** — 指数定理（B1）は奇数を許す唯一の既知経路。n を TTT の構造（正四面体・2T）から出せれば、世代数 3 の導出になる
2. **C4：¹⁶O の正四面体スペクトル** — A9 の「1, 2, 5 が抜け、6 が 2 重」を実測レベルと照合する。自由パラメータは回転定数 1 つ
3. **A3 + B3：2T と奇数 B** — 2T が本物として働くのは奇数 B のみ。これを TTT の 2T（McKay で E₆）側とつなぐ構成を書く

**避けること**：殻模型で説明済みの量（四重極、スピン）を幾何で読み直すこと／新しい B を「魔法数」として次々に照合すること（数の性質は豊富なので、毎回何かが見つかる）。
