## 5. 提案された「TTT 定量的モデル」への判定

> Q_meas(B) = Q_sp(B) + Q_core(B)
> ① 幾何学は「舞台」：Goldberg ベクトル (h,k) が魔法数 B を決定し、核の安定性を支配
> ② 最後の核子は「演技者」：軌道（n, l, j）が single-particle 効果を決定
> ③ 核心分極は「集団効果」：single-particle 効果を上回り、変形の符号と大きさを支配

| 項目 | 判定 | 理由 |
|---|---|---|
| 式 Q_meas = Q_sp + Q_core | ○【既知】 | 殻模型の標準的な分解。ただし TTT 固有の内容はまだ入っていない |
| ① | **✗** | (h,k) が決めるのは「無質量パイ中間子・有理写像近似でのスカーミオンのエネルギー」の予想列。実在核の安定性とは結びついていない（4-4）。しかも正二十面体対称では Q = 0（A6）なので、幾何は Q に寄与しない |
| ② | ○【既知】 | 殻模型そのもの（B8） |
| ③ | **✗（修正して○）** | 核心分極は **符号を変えない**。符号は「粒子か穴か」で決まり 6/6 一致。核心分極は重い核で大きさを 2〜4 倍に増強する（B9） |

**修正版（この形なら実測と整合する）**

- Q_sp(n, j) = −(2j−1)/(2j+2)·⟨r²⟩·(2j+1−2n)/(2j−1)·e_eff … 符号は n/(2j+1) が 1/2 未満か超えるかで決まる
- Q_core は Q_sp と同符号で、閉殻から遠い核ほど大きい
- **幾何学（二十面体殻）は、このモデルのどの項にも入らない。** これは 1949 年以来の殻模型であり、TTT のモデルと呼ぶには TTT 由来の量を 1 つ以上含める必要がある

## 6. 次に進むなら（TTT 固有の予言を立てる候補）

1. **C8：三重項か 2 + 1 か** — 磁束 3 の線（B10）を本線にするかどうかがここで決まる。先に決める
2. **B10 の前提①を導く** — 「内部球面に正四面体の対称性が載る」を、双極ゼロ公理（XYZ = ±1）から出せるか。A14 で XYZ = ±1 の二正四面体が磁束 3 の穴と一致したので、ここが最短の接点
3. **C4：¹⁶O の正四面体スペクトル** — A9 の「1, 2, 5 が抜け、6 が 2 重」を実測レベルと照合する。自由パラメータは回転定数 1 つ。実測で白黒がつく唯一の候補
4. **A3 + B3：2T と奇数 B** — 2T が本物として働くのは奇数 B のみ。これを TTT の 2T（McKay で E₆）側とつなぐ構成を書く

**避けること**：殻模型で説明済みの量（四重極、スピン）を幾何で読み直すこと／新しい B を「魔法数」として次々に照合すること（数の性質は豊富なので、毎回何かが見つかる）／角度の半分・差・和などを事後に組み合わせて実測値に合わせること（C7 の型）。

## 7. B と N（原子と原子核）

**【A】物質**
- A16：ダイヤモンド／立方晶 BN の結合方向は、二つの副格子で XYZ = +1 と XYZ = −1 の正四面体に分かれる。
- A17：蜂の巣格子で副格子に ±Δ の差を付けると、ギャップは 2Δ（Semenoff 質量、πOπ の「O」に当たる）。グラフェンは Δ = 0 でギャップなし、h-BN は Δ ≠ 0。

**【B】原子核**
- B11：同じ軌道の核子 2 個は、J + T が奇数の組だけが許される。
  - ¹⁴N ＝ p1/2 の 2 個で、(J, T) = (1, 0) と (0, 1) の二つだけ。磁気モーメントは 0.373（実測 0.404）。
  - ¹⁰B ＝ p3/2 の 2 空孔で J = 3 を作れる。磁気モーメントは 1.880（実測 1.801）。
- B12：⁶Li（1⁺ 基底）と ¹⁰B（3⁺ 基底）の順序の違いは、二体力だけの計算では再現できず、三体力で再現される。¹⁴C → ¹⁴N のβ崩壊の異常な遅さも、三体力の効果である。

## 8. スカーミオンの量子化（FR 制約の独立計算）

手法の較正：B = 1（核子 1/2⁺、Δ 3/2⁺）、B = 4 立方体（0⁺, 4⁺, 6⁺, 8⁺）、B = 6（1⁺, 3⁺）、B = 8（0⁺, 2⁺, 4⁺）をすべて再現。

**【A】B = 10（D₄d）**
- A18：FR 符号は C₂′ と σ_d で −1、それ以外は +1。
- A19：T = 0 で許されるのは 1⁺, 3⁺, 4⁻, 5±, 6⁻, 7±, 8±（J ≤ 8）。1⁺ と 3⁺ はどちらも L₃ = 0 の状態なので、剛体回転子ではエネルギー比 E(3)/E(1) = 6 となり、基底状態は必ず 1⁺。¹⁰B の 3⁺ は許されるが基底状態にならない。
- A20：B = 6 と B = 10 の許容状態は同一。⁶Li では予言が当たり、¹⁰B では順序が逆。

**【B】B = 10（文献）**
- B13：質量ありの D₂h 解（Battye–Manton–Sutcliffe–Wood 2009）でも 1⁺ が基底状態で、3⁺ は励起状態。著者自身が失敗と認めている。二体力だけの原子核計算と同じ失敗の型。

**【A】B = 7（I_h、十二面体）**
- A21：反転がアイソ回転なしの対称性になっているので、χ_FR(P) = +1 は向きの約束に依存しない。したがって剛体の状態はすべて正パリティ。T = 1/2 で許されるのは 7/2⁺, 13/2⁺（J ≤ 15/2）。⁷Li の 3/2⁻ は剛体では原理的に出ない。
- A22：振動 1 量子の場合、T = 1/2 の 3/2⁻ を許すのは T₂u と H_u、1/2⁻ を許すのは G_u だけ。H_u だけで 1/2⁻ を作るには 3 量子必要。
- A23：D₅ への変形（反転を破る）で 3/2 が正負両パリティで許される。D₅d への変形では 3/2⁺ のみ。

**【B】B = 7（文献）**
- B14：実際の最低振動モードは H_u < H_g < T₂u < G_u（Baskerville 1999）。Halcrow（2016）は H_u 空間の量子化で 3/2⁻ を基底状態にしたが、1/2⁻ が 5 MeV 深すぎる。

**【C】**
- C9：G_u を加えて H_u ⊕ G_u の空間で量子化すれば、1/2⁻ は G_u の 1 量子として 3/2⁻ のすぐ上に来る（A22 からの予想、未検証）。

## 9. 帯（π）とねじれ

**【A】群論**
- A24：I_h で 5 回軸を固定する部分群は D₅d（20 元）。**D₅h は I_h の部分群ではない**（S₅ を含まない）。
- A25：Ind_{D₅d}^{I_h} の結果は次のとおり。
  - E₂g → T₂g ⊕ G_g ⊕ H_g
  - E₂u → T₂u ⊕ G_u ⊕ H_u
  - A₁u → A_u ⊕ H_u
  - A₂g → T₁g ⊕ T₂g
- A26：帯（10 頂点／10 辺／10 面）のどの自由度でも、E₂g と E₂u は同数現れる。g と u の違いは上下の環の同位相・逆位相であり、帯の幾何からは選べない。
- A27：π/5 のねじれ（上下の環の逆回転）は A₁u。棒磁石（軸性ベクトル）は A₂g。
- A28：I_h における球面調和関数の分解で、各表現が初めて現れる l は次のとおり。A_g は 0、T₁u は 1、H_g は 2、T₂u と G_u は 3、G_g は 4、H_u は 5、T₁g は 6、T₂g は 8、A_u は 15。

**【B】物理との接点（今回の最重要項目）**
- B15：π/5 のねじれ（A₁u）は、B = 7 の最低振動モード H_u の中で D₅ 対称を保つ唯一の方向であり、Halcrow と Manko–Manton が ⁷Li の 3/2⁻ を得るのに使った変形と一致する。
  - 流れ：**帯のねじれ → 6 軸に誘導すると H_u → B = 7 の最低モード → ⁷Li の 3/2⁻**
- B16：棒磁石（A₂g）を 6 軸に誘導すると、回転とアイソ回転のゼロモード（T₁g ⊕ T₂g）になる。これは振動ではなく「向き」の自由度。

**【提案・記法】**
- O ＝ 5 回軸の選択（D₅d からの誘導）、π ＝ A₁u（ねじれ）とすると、OπO = A_u ⊕ H_u。TTT の文字列を誘導表現として一意に計算でき、実際の振動スペクトルと照合できる。

## 10. 閉じる形（極と帯）
