## 1. 中から3、外から4（Block 1）

本人の提示：一つの宇宙（境界）を見るには中と外から見る必要がある。中では3個しか見えず、外からは4個が見える。

- 閉じた境界の宇宙＝3次元球面。中からは境界に沿った3方向、外からはそれに垂直な1方向を加えた4方向。
- 長さ1の四元数（実部1＋虚部3）全体がこの3次元球面。自由度 4 − 1 ＝ 3。
- **q と −q は同じ3次元回転**を表す。一つの回転に二つの極が対応する（双極）。
- 四面体でも同じ形：3次元で体積を囲む最小の図形は頂点4つ、一つの頂点から見えるのは他の3つ（1/3 のノートの「球4つ、外1・中3」と同型）。

## 2. 外から見た回転の独立性（Block 2）

1/3 のノートで、直交する回転が非可換（[Lx, Ly] ＝ Lz）なため回転場どうしの独立性が穴として残った。

- 4次元では回転面が 6（3次元では 3）。
- 6つが **左回り3つ・右回り3つ** に分かれ、**二組どうしは可換**。
- 各組の中の3つは非可換のまま。

→ 「双極の二つの極がやり取りしない」は外から見ることで導かれる。各極の中の3つの場の独立性は未解決。

## 3. F・B・I ＝ −1 と F・B・I・π ＝ 1（Block 3）

本人の提示：F×B×I ＝ −1 で FBIπ ＝ 1。

| 式 | 値 |
|---|---|
| F² ＝ B² ＝ I² | −1 |
| F・B・I | −1（ハミルトンの関係） |
| e^{πu}（u は単位虚数） | −1 |
| F・B・I・e^{πu} | ＋1 |

- π は数の 3.14… ではなく**位相として半回転させる操作**と読む必要がある（数として掛けると −π）。TTT の「π＝位相」の定義と一致。
- F・B・I は3次元の回転としては各軸まわり180°。その積は**中から（3次元回転）では恒等（＋1）、外から（四元数）では −1**。もう一度 π を掛けて初めて ＋1 に閉じる。スピン1/2の 360°で符号反転・720°で元に戻る性質と同じ構造。
- 中の3（F・B・I）と外の1（π）で 1 に閉じる。

## 4. XYZ と FBI の関係（Block 4）

| 要素 | 中身 | 2乗 |
|---|---|---|
| X, Y, Z | 3本の軸 | ＋1 |
| F ＝ ZY, B ＝ XZ, I ＝ YX | 3つの回転面 | −1 |
| XYZ | 3軸すべての積 | −1 |

- F・B・I ＝ −1、F・B ＝ I。
- 面の向きを逆（F ＝ YZ …）にすると F・B・I ＝ ＋1。**−1 になるかは右手系・左手系で決まる**（向きの双極）。
- 基底は 1, X, Y, Z, XY, XZ, YZ, XYZ の 8 ＝ 2³（各軸を使う・使わないの二択）。

## 5. XYZ・RST・FBI の役割（Block 5）

本人の提示：ベクトルは原点からの方向と大きさ。それに加えてその先の向きが要る。それが回転3軸 RST。

| 組 | 中身 | 自由度 | 双極のどちら |
|---|---|---|---|
| XYZ | 原点からの方向と大きさ（位置） | 3 | 直線運動（格子） |
| RST | 先端の向き（姿勢）、回転3軸 | 3 | 曲線運動（球） |
| FBI | 回転の生成元（四元数の虚数単位） | ― | RST を表す道具 |

- 1/3 の 18 ＝ 3場 ×（XYZ の3 ＋ RST の3）。
- 回転行列 ＝ RST の3軸を XYZ で表した 3×3。成分9 − 直交の制約6 ＝ 自由度3。
- 位置と向きをまとめて表す双対四元数：成分8 − 制約2 ＝ 自由度6。

## 6. 3×3×3 の表 ε と 2²⁷（Block 6・7）

FBI の掛け算の規則は 3×3×3 の27マスの表で決まる：

$$F_i F_j = -\delta_{ij} + \sum_k \varepsilon_{ijk} F_k$$

| 値 | マスの数 |
|---|---|
| ＋1 | 3 |
| −1 | 3 |
| 0 | 21 |

- **27マスに ＋、−、0 を置いた双極ゼロの表**。どの2つの添字を入れ替えても符号が反転する表は、3次元では定数倍を除きこれただ一つ。
- 本人の提示：XYZ, RST, FBI の関係は双極の27乗。((2³)³)³ ＝ 2^(3·3·3) ＝ 2²⁷ ＝ 134,217,728 は、27マスすべてに ± を割り当てる数。
- 2²⁷ は3×3×3が取りうる双極の状態の全体、ε はその中で回転として閉じる唯一の状態。
