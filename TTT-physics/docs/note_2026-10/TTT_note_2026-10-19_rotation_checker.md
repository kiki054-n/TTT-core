# TTT 検証ノート 2026-10-19 朝：回転の起源・2×2×2 型・銀河の回転・見えていない市松模様

検証スクリプト：`rotation_checker.py`（63 assert、全通過）

回転は力ではなく、軸が決まる順番と拘束 XYZπ＝1 から生まれる。全体の回転は常に 0 で、局所に ± の回転が散らばる。この ± を市松模様として数えると、正六面体・球・正八面体が白黒の釣り合いを保って重なるのは中心がマスの頂点にあるとき（2×2×2 型）だけだった。観測とは一部が合い一部が合わず、市松模様にはまだ観測でとらえられていない関係が残っている。

## 1. 力の蓄え

陽子側のエネルギーの出所は「125 に 2000 個を押し込む力」とする（本人）。体積が変わらなくても、入ってくる要素は外から中へ 1 マス移動するので仕事がかかる。力を中の密度に比例と置く。

```latex
F(N) = c\,\frac{N}{125},\qquad E = \int_0^{2000} c\,\frac{N}{125}\,dN = 16000\,c
```

| 入り方 | 1500 側が受け取る分 | π で蓄える（÷3） |
|---|---|---|
| 1500 が先、500 が後から外郭 | 9000c | 3000c |
| 2000 に比例して混ざる | 12000c | 4000c |

## 2. 回転が生まれる仕組み

| 段 | 本人の立場 | 計算で出たこと |
|---|---|---|
| 軸の順番 | Z が先に決まり、次の分かれが X・Y を決める。中心点は一様に多点生まれるので、分かれは Z からずれた位置でも起きる | z0 ずれた位置で X が分かれると L ＝ (0, z0·p, 0)。±z0 の対で合計 0 |
| 中心の配置 | 2×2×2 型を採用（最初の中心が 8 つのまとまりの接点） | 回転は XY 平面の軸だけ（Lz ＝ 0 厳密）、成分 ±1/2 p、上下の層で逆向きの渦、合計 0 |
| 隙間を埋める | 正八面体 → 正六面体、3 点で広げるので回転が起きる | 隙間 20/3（角ごとに 5/6）、8 つの重心 ＝ 2×2×2 の中心。Z→X→Y の向きは 3·sx·sy·sz、右 4・左 4 の市松 |
| 拘束 | 6 点が正八面体を押し、XYZπ＝1 なので π で中心が回る | 体積比 8 ÷ 4/3 ＝ 6（10-15 のマスを破る条件 6 と同じ）。±2 になると π ＝ 1/8 |
| 衝突と蓄え | 外へ出られないエネルギーは質量にため込まれ、質量は回転する | 衝突で直進は止まるが L は残る。ずれ b が最小の大きさ R ＝ b/(2√k) を決める |
| 空間 | 質量が集まると双極に空間も大きくなる。広がる空間は回転なし、質量のできた空間は回転 | 引きずりは質量と同じ向きで一般相対論と両立。± は隣の領域どうしで分かれる |

```latex
\frac{d\pi}{\pi} = -\left(\frac{dx}{x}+\frac{dy}{y}+\frac{dz}{z}\right),\qquad
\mathbf{L} = \mathbf{r}\times\mathbf{p},\qquad
\sum_{\text{領域}} \mathbf{L}_i = 0
```

2 種類の回転：中心が全体を巡る回転（位置と直交、Z を巡る渦）と、中心がその場で回る回転（対角線方向、隙間の 3 点押し出し）。

## 3. 市松模様の白黒

同じ中心で重ね、白黒の差は中心のマスと同じ色を＋とした値。

| マス | 形 | 完全に入るマス | 切れたマス | 外れるマス | 体積 | 白黒の差 |
|---|---|---|---|---|---|---|
| 5×5×5 | 正六面体 | 125 | 0 | 0 | 125 | ＋1（63 と 62） |
| 5×5×5 | 球 | 19 | 98 | 8 | 65.45 | −0.32 |
| 5×5×5 | 正八面体 | 7 | 50 | 68 | 20.83 | ＋25/6（12.5 と 25/3、3 : 2） |
| 6×6×6 | 正六面体 | 216 | 0 | 0 | 216 | 0 |
| 6×6×6 | 球 | 56 | 128 | 32 | 113.10 | 0 |
| 6×6×6 | 正八面体 | 8 | 72 | 136 | 36.00 | 0 |

平面（5×5）：円は完全 9・切れ 16・差 0.67、菱形は差 2.5。6×6 ではどちらも 0。菱形：円：四角の面積は 2 : π : 4。

- 偶数で 0 になる理由：X 方向の鏡映で色が n−1 ずれ、n が偶数なら白黒が入れ替わる。6 に特有ではなく 2・4・8 でも同じ
- 完全に入るマスが形を表す：5 の正八面体 7 ＝ 中心 ＋ 軸上 6、5 の球 19 ＝ 1 ＋ 6 ＋ 12、6 の正八面体 8 ＝ 中心の頂点を囲む 2×2×2
- 回転軸（対角線）に垂直な中心の切り口：正六面体も正八面体も正六角形（向き同じ、大きさ 2 : 1）、球は円。格子はハニカムで敷き詰められる
- ハニカムは白黒が釣り合う理由ではなく、回転軸に垂直な面の模様として現れる

## 4. 観測との照合

| 観測 | 結果 | TTT との関係 |
|---|---|---|
| SDSS 銀河ペア（arXiv:0908.2486） | 回転の大きさに弱い相関、軸の向きの揃いははっきりしない | 支持も否定もしない |
| Galaxy Zoo の回転の向き（Jimenez ほか 2010） | 古い渦巻銀河は約 10 Mpc/h で同じ向きに揃う（5σ 以上） | 市松模様より大きい段の構造として読む必要 |
| 潮汐の尾を持つ相互作用ペア（arXiv:1312.0560） | 同じ向きが逆向きの約 2 倍。逆向きは早く合体するためかもしれない | 逆向きの組（対角・上下）は合体して打ち消され残らない、と読める |
| 近い銀河どうし（Sofue 1992 ほか、arXiv:1912.05429 で引用） | 隣どうしは直交する回転を持つ傾向 | 2×2×2 で辺を共有する隣は内積 0 で直交、一致 |

「隣は逆向き」という単純な形は観測と合わない。直交の傾向は古い小規模な観測に基づき、確かな一致とは言えない。

## 5. 観測でまだとらえられていない市松模様の関係

観測は銀河一つ一つの回転の向きを見ているが、市松模様そのもの（隣どうしの関係の並び方）はまだとらえられていない。四角と円の市松模様が同じ空間に存在するには、まだ見えていない模様が要る（本人）。

1. **四角と円の間にある第三の模様**：平面では菱形、立体では正八面体。菱形の境界はマスの対角線を走り、同じ色を斜めに結ぶ。四角の格子で数える限り、この斜めの縞は拾えない
2. **回転軸に垂直な面のハニカム**：回転の向きを揃えて見るなら、視線方向ではなく、それぞれの回転軸に垂直な面で並びを見る必要がある
3. **切れたマスの層**：球の境界では必ずマスが切れる（5×5×5 で 98、6×6×6 で 128）。四角でも円でもない層が、物理で何に当たるのか（境界、外郭の O、膜）は未定
4. **奇数の段の余りの向き**：5×5×5 では正六面体と正八面体は中心と同じ色が多く、球だけは反対。この余りの行き先（質量、π、回転）を決める必要がある
5. **逆向きの組が消える仕組み**：逆向きの組が合体して打ち消されるとき、回転のエネルギーは質量にため込まれるはず。合体した質量に蓄えが多いかは未照合
6. **市松模様の大きさの段**：1、2×2×2、5×5×5、6×6×6… のどの段が銀河のどの大きさに当たるか、段が上がるごとに模様が反転するか揃うかが未定
7. **±1/2 と 2 種類の回転**：巡る回転と、その場の回転が、観測の「小さい銀河はフィラメントに平行、大きい銀河は直交」と対応するかは未照合

## 6. 判定

- **ADOPTED**：力の蓄えは「125 に 2000 を押し込む力」、総和 16000c／Z 先行と分かれのずれから L ＝ z0·p／2×2×2 型：Lz ＝ 0、成分 ±1/2、合計 0、上下で逆向きの渦／辺を共有する隣は直交、対角と上下は逆向き／隙間の重心 ＝ 2×2×2 の中心、3 点の向き 3·sx·sy·sz／体積比 6、π ＝ 1 → 1/8／衝突後も L は残り R_min ＝ b/(2√k)／広がる空間は回転なし、質量のできた空間は質量と同じ向きに回る／偶数 n で正六面体・球・正八面体の白黒が 0／回転軸に垂直な切り口は正六角形 2 : 1
- **REJECTED**：隣の領域は逆向き（観測で逆向きは少ない）／回転する質量のまわりの空間は逆向きに回る（引きずりと食い違う）／ハニカムが白黒の釣り合いの理由
- **REVISED**：「隣は逆向き」→ 辺を共有する隣は直交、対角・上下は逆向き
- **OPEN**：§5 の 7 項目／p ×（マスの辺）が ℏ に当たるか／回転が膨張で薄まらない理由を「束ねられた質量に入る」以外から出すこと
