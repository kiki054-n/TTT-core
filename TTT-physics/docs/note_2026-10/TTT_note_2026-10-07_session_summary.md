## 2. 主張と照合結果

### 2.1 電子の静止質量は内部の運動エネルギーである

**主張**：電子は質量があるため光速になれない。電子の静止質量は電子内の運動エネルギーといえる。

| 読み方 | 判定 |
|---|---|
| 静止質量＝静止系での内部エネルギー | ✓ 定義として成立 |
| 光速の成分が向きを入れ替え続け、その頻度が質量として現れる（ジグザグ描像） | ✓ 標準模型と整合する解釈 |
| 内部の構成粒子の運動エネルギーが質量 | ✗ 10⁻¹⁸ m に閉じ込めると運動エネルギー約200 GeV となり、電子質量の約40万倍 |

### 2.2 電子の構造：ねじれ五角双錐（πOπ）

**主張**：πOπ で構成される電子はねじれ五角双錐の20面体構造で、O＝光速円運動、π＝回転軸。

- ✓ ねじれ五角双錐（五角反柱＋上下の五角錐）は正二十面体を5回対称軸から見たものと厳密に一致（頂点12＝2＋5×2、面20＝5＋10＋5）

### 2.3 創成モデル：OOOπ

**主張**：軸は ＋F と −F を結ぶ直線で、その直線も回転し、両端の円運動でリングを形成する。軸の回転は面を作り、それも回転する。π はその軸の内部運動エネルギーである。粒子の起源は、閉じ込める3つのリングと軸の内部運動エネルギー＝OOOπ で構成される。

- ✓ 3つのリングは3次元の回転の3自由度（回転3軸 RST、四元数の3自由度）と数が一致
- ✓ 「向きを変え続ける内部運動がエネルギーを閉じ込め、静止質量として現れる」は既知の物理（箱に閉じ込めた光、ジグザグ描像）と同じ構造
- △ 「光速に拘束されないエネルギー」は次のように言い直すと正確になる

> 速さは光速に拘束されるが、閉じ込められるエネルギー量は拘束されない。

理由：回転をいくつ重ねても、各瞬間の角速度はベクトルとして足し合わされ1本の瞬間回転軸のまわりの回転になる。

$$\boldsymbol{\omega}_{\text{全}}=\boldsymbol{\omega}_R+\boldsymbol{\omega}_S+\boldsymbol{\omega}_T,\qquad |\mathbf{v}|=|\boldsymbol{\omega}_{\text{全}}\times\mathbf{r}|\le c$$

一方、運動エネルギー $K=(\gamma-1)mc^2$ には上限がない。

- 参考：太さゼロの軸自身の自転は慣性モーメントがゼロで運動エネルギーを持たず、太さがあれば表面速度が光速に拘束される。スピンを古典的な自転とみなすと表面速度が光速の約100〜170倍になる問題（1925年、ローレンツの指摘）がある。オハニアン（1986）はスピンをディラック場内の光速の循環エネルギー流として説明しており、「O が光速で循環、π はその向きを定める軸」と同じ描像になる

### 2.4 エネルギーの階層

**主張**：

| 段階 | 中身 |
|---|---|
| OOOπ | エネルギー |
| OπO | 境界の中のエネルギー。空間の広さの単位 |
| 質量 | OπO が拘束され容量収束（格子収束）したもの。格子拘束の単位はテトラ |
| ヒッグス場 | 125 の立方体の中に格子拘束粒子が最密に詰まった状態（粒子拘束なら125個の粒子） |

- 125 の立方体に 162 の球が入る拘束条件がある。テトラを粒子として立方体拘束すると OOOπ の 1/4 の端数が出て 125.25 になる
- 125 の OπO 空間に、格子拘束された質量粒子が宇宙空間にあることになる

**照合**：
- ✓ 「質量＝境界に閉じ込められ収束したエネルギー」は陽子質量の構造と同じ骨格
- △ 125.25 は数え方から出る**個数**である。「ヒッグス場＝最密拘束の状態」という構造の主張なら単位の問題は生じない。ヒッグス粒子の質量の値（125.20 ± 0.11 GeV）と結びつける場合は GeV という単位に依存し、単位のない比ではヒッグス/陽子＝133.4、ヒッグス/電子＝約245,000 となり一致しない
- 補足：125 GeV はヒッグス粒子（場の振動）の質量。ヒッグス場そのものの大きさは真空期待値 246 GeV

### 2.5 宇宙の3成分

**主張**：

| 成分 | 割り当て | 観測（Planck 2018） |
|---|---|---|
| バリオン | 質量 | 4.9% |
| ダークマター | 質量と空間を形にしている（空間を曲げている）エネルギー | 26.5% |
| ダークエネルギー | 宇宙空間の OπO のエネルギー。宇宙空間を閉じている境界エネルギーともいえる | 68.5% |

光も素粒子もエネルギーであり、質量と拘束軌道エネルギーの関係は見えていない。

**照合**：
- ✓ 役割の割り当ては一対一で対応
- ？ 比の導出：37/125 = 29.6% は物質全体 31.5% に近い。質量拘束9粒子とすると 9/125 = 7.2% でバリオン 4.9% と合わない。バリオンとダークマターの分け方は構造から未導出
- ダークエネルギーの2つの言い方は観測上区別される

| 読み方 | 膨張時の振る舞い | 判定 |
|---|---|---|
| 空間（体積）あたり一定の OπO のエネルギー | 密度一定、w = −1 | ✓ 観測 w ≈ −1.03 ± 0.03 と整合 |
| 境界（面）に乗ったエネルギー | 体積あたり薄まる、w = −2/3 | ✗ |

- 通常の物質の拘束エネルギーは、重力がエネルギーをすべて量るため、すでにバリオン 4.9% に含まれている（元素合成と背景放射の2つの独立測定）。ダークマターに上乗せできない
- 光子は約0.005%、ニュートリノは0.3%未満で、ダークマターの量に届かない

### 2.6 重力と慣性

**主張**：そもそも重力は存在しない。運動は質量に作用した力が慣性として保存されている結果である。引力は質量にたまった慣性の作用で働いている。質量と OπO は作用しあい、OπO の空間を質量が運動していれば OπO はひずむ。光が曲がるのは、質量と質量の運動で空間が曲げられている結果である。

**照合**：
- ✓ 「重力は力ではない」：一般相対性理論でも自由落下は曲がった時空での慣性運動
- ✓ 「慣性と重力は同じものの表れ」：等価原理。慣性質量と重力質量の一致は 10⁻¹⁵ の精度で確認（MICROSCOPE）
- ✓ 「運動する質量は空間をよりひずませる」：慣性系の引きずりとして実測（Gravity Probe B ほか）
- △ 慣性を「外から加えられた運動」と読むと、静止物体どうしの引力（キャベンディッシュの実験）と、静止質量のない光の曲がり（1.75秒角）と合わない。慣性を**内部運動のエネルギー**と読めば両方と矛盾しない
- 先行例：MOND（ミルグロム）の「慣性の方が変わる」解釈。銀河の回転曲線はダークマターなしでよく説明できるが、銀河団と背景放射の音響ピークは説明しきれていない

### 2.7 インフレーションの残留ひずみとダークマター

**主張**：銀河の回転運動と向心力を考えるときに矛盾がある。質量創成のインフレーションの空間のひずみは OπO に残っており、宇宙は広がりつつも解消できていない。宇宙全体の OπO の配置は均一でない。ガスに運動エネルギーがあり慣性が蓄えられていれば、恒星と違う動きをする。

**照合**：
- ✓ 銀河の回転速度が見えている質量の向心力で足りないことは、ダークマターが必要とされる元々の理由
- ✓ インフレーション期のゆらぎ（約10万分の1）が残り、構造の種になったことは標準宇宙論と同じ方向
- ✓ ガスと星が別に動くことは観測どおり
- ？ 弾丸銀河団（1E 0657-56、Clowe ら 2006）では、光の曲がりから求めた空間のひずみの中心が、**質量の大きいガスではなく軽い星の側**にあった（約8σ）。ガスが失った運動エネルギーは熱（X線で光る高温ガス）としてガスの場所に残っているため、エネルギーで数えてもガスの側が重い。「なぜ分かれたか」は慣性で説明できるが、「なぜひずみが軽い星の側にあるか」は未説明

**構想と観測を整合させる条件**：OπO の残留ひずみが
1. 星の形成時から星と同じ場所にあり
2. それ自体が慣性を持ち
3. ガスと衝突せず星と一緒に進む

ならば、観測が要求するダークマターの性質（冷たく衝突しない）と一致する。

## 3. 本人の立場（考察の現在地）

インフレーションの状況を想像してみないとわからない。OOOπ はインフレーション的に増大し質量拘束も始まり、その拘束が軽い原子から重い原子まで質量の引力によるのか、インフレーションによる圧力が慣性力になったものなのか、想像しきれない経過があるはずである。インフレーション以前の創生原理から、格子拘束原理と、粒子と空間の球と正6面体の双極関係を1つにみる見方の理論考察の途中であり、すべてが解決できるわけではない。

- 補足（照合側）：「引力か圧力による慣性力か区別しきれない」ことは等価原理（加速による慣性力と重力は局所的に区別できない）と同じ構造で、重力を慣性の表れとして扱う立場と矛盾しない
