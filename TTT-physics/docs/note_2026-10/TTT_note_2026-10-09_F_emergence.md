## 1. 出発点（本人の提示）

XYZ 空間で B と I が円運動し、F による単振動が起きる。その両端で円運動。(1,1,1) と (−1,−1,−1) の空間で、円運動3と単振動1の4つの運動がある。XYZ・FBI・RST の関係で回転している。

問い：**F（単振動）はどこから発生するか。**

## 2. 逆向きの回転から単振動が出る（Block 1）

体対角線 n ＝ (1,1,1)/√3 に垂直な面で、B を角速度 ＋ω、I を −ω で回す。

$$\mathbf{F}=\mathbf{I}\times\mathbf{B}=I_0B_0\,\sin(2\omega t-\varphi)\;\hat{\mathbf n}$$

- F は常に体対角線の上にあり、＋F と −F の間を往復する。
- 振動数 2ω：二つの円運動から一つの単振動が出るとき、振動数は倍になる。
- 時間平均ゼロ：＋F と −F が釣り合い、総和ゼロを保つ。

## 3. 同じ向きの回転・別の面の回転（Block 2・3）

| 回り方 | F |
|---|---|
| 同じ面・逆向き | 体対角線上の単振動（2ω、平均ゼロ） |
| 同じ面・同じ向き | 一定の F（大きさ I₀B₀ sin φ）、振動しない、平均がゼロにならない |
| 別々の面 | 向きが一本の線に定まらない |

**F が単振動として生まれる条件は「同じ面で逆向き」だけ。** 10-05 ノートの「外から見ると回転は左回り3・右回り3に分かれる」の左右一組が、B と I の逆回転にあたると読める。

## 4. Cl(3) での位置づけ（Block 4）

10-05 ノートの定義（F ＝ ZY、B ＝ XZ、I ＝ YX）をパウリ行列で表して確認した。

| 式 | 値 |
|---|---|
| F・B・I | −1 |
| F＋B＋I | −(X＋Y＋Z)·XYZ（体対角線の双対） |
| (F＋B＋I)² | −3 |
| u ＝ (F＋B＋I)/√3 | u² ＝ −1 |
| (1＋F＋B＋I)/2 | e^{πu/3}、X→Y→Z を巡回（120°） |
| e^{πu} | −1 |
| F・B・I・e^{πu} | ＋1 |
| (e^{πu/3})⁶ | ＋1（3次元の回転では 3 回、四元数では 6 回：双極で 2 倍） |

- 三つの回転 F・B・I を等しく重ねると、一本の瞬間回転軸 ＝ 体対角線になる（10-07 ノート：角速度はベクトルとして足し合わされ 1 本の軸になる）。
- 10-05 ノートで「π は位相 e^{πu}」としたときの u は任意の単位虚数だった。ここでその u が**三つの生成元の和として体対角線の向きに決まる**。

## 5. 読み

- 円運動3（F・B・I の三つの回転面、外から見て RST の3）と、単振動1（体対角線 ±F の往復）で、「円運動3と単振動1」の4つの運動になる。
- 単振動は、二つの円運動が逆向きに重なって生まれる。振動数が倍になることは、「誕生も双極であるから 1 から 2」と同じ形をしている。

## 6. 限界

- B は擬ベクトル、I（電流）は真のベクトル（定義台帳 R6）。ここでは B と I を同じ面の回転ベクトルとして扱っており、パリティでの区別は使っていない。Cl(3) のバイベクトルで書けば非対等性は消える（R6 の覆す条件）が、Block 1 はベクトルの外積で計算している。
- B と I を逆向きに回すものは何か、は導いていない。
- 光速での飽和・誕生（立方体と球の数列）との量的な結びつきはまだない。

## 7. 次の課題

- Block 1 を Cl(3) のバイベクトルのまま計算し直し、R6 の非対等性の問題を消す。
- 単振動の 2ω と、球の数列の倍率 ×3（親1＋子2）を結ぶ式があるかを調べる。
