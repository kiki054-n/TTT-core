## 0. 要旨

陽子と電子の対が 125/37 の多層多面体ポテンシャルに拘束されて安定粒子になる、という着想から出発し、次を得た。

1. **飽和の幾何** — 125 → 216 の飽和は、「中心が 1 つ余る状態（63:62）」から「中心不在の 108+108 の双極対」への移行として書ける。各 108 は四面体孔を中心とする fcc クラスターで、最初の殻は正四面体。[A]
2. **電荷の構成** — O = +1/6、π = −1/3 と置くと、クォーク・陽子・中性子・電子・水素の電荷がすべて閉じる。陽子の余りの 6O と電子の 6π がそろって水素が中性になる。[A]（算術として）
3. **電子の g 因子と歪みゼロ** — リング O（円）と軸 π（直線）を逆回転させ、閉じ込めの場がスピンを担う構成で、S³ 上に置くと半径の比が消え g は純粋な数になる。**スピン 1/2 の条件（歪み ℓ=2 がゼロ）と g = 2 を同時に課すと解は一意**: 閉じ込めの場 3/4・リング＋軸 1/4、位置は**正四面体角 cosθ = ±1/3**。OπO の 1/4 と正四面体角が仮定なしに出る。電荷の四重極（−1）は未解決。[B]
4. **幾何の骨格** — リングと軸は S³ をクリフォード・トーラスで等分した二つの芯。「近づくが戻らない」の最適は黄金比で、双極公理 Y = 1/X に差 1 を加えると φ に決まる。[A]
5. **記法** — 位置と回転のテンソル積 r⊗ω は 1 ⊕ 3 ⊕ 5（スカラー・回転・歪み）に分解され、伝わる波の自由度として光（±1）と重力波（±2）の偏極数が同じ式から出る。[A]

到達していない点については、**到達のための手法**を §2 に示す。

## 1. 検算済みの結果 [A]

### 1.1 角殻と飽和

立方体を角から ⟨111⟩ 方向（正四面体の 3 回軸）に剥がすと、殻の点数は中心六角数 3k(k−1)+1 になる。

    1 + 7 + 19 + 37 + 61 = 125 = 5³
    125 + 91 = 216 = 6³

37 は 125 の第 4 殻、91 は 125 の外に付く第 6 殻。隣り合う立方数の差は必ず次の殻になる。

### 1.2 偶奇分割 — 108 の構成的な出所

座標和の偶奇で点を分けると、それぞれが fcc 格子になる。

| n³ | 偶 : 奇 | 中心の格子点 |
|---|---|---|
| 125 | 63 : 62 | あり (2,2,2) |
| 216 | 108 : 108 | なし |

- 125 の差 1 は、ちょうど中心点。
- 足される殻 91 は偶 45・奇 46 に分かれ、63+45 = 62+46 = 108。
- 各 108 の中心まわりの殻は 4, 12, 12, 16, 24, 12, 12, 12, 4。**最初の殻は正四面体**、中心は四面体孔。
- 内側 8 点は偶の正四面体と奇の正四面体が組んだ星形八面体。
- 二つの 108 を入れ替えるのは **C4**（C3・C2 は各 108 を保つ）。各 108 の内部は T、対の入れ替えには O が要る。

**108 = 6³ の偶奇分割の片側**。これまでの 4×27 型の読みと違い、点を数えて検算できる構成である。
注: 偶数辺（8, 64, 216, 512）はすべて等分される。6 の選択は 125 からの連鎖による。

### 1.3 立方格子と密充填の一致点

fcc 四面体孔中心の球状クラスターの累積は 4, 16, 28, 44, 68, 80, 104, 140, 152, 180, **216**。立方数との共通値は 216 のみで、最初の 6 殻（80 点）は §1.2 の 108 と一致する。殻どうしの途中の対応はない（角殻は角から、クラスターは中心から育つ）。

### 1.4 成長と拘束

隣接結合を拘束として数えると、1 点あたり

    3n²(n−1) / n³ = 3(1 − A^(−1/3)),  A = n³

原子核の液滴模型の体積項・表面項と同じ形で、表面項/体積項 = 1（原子核のあてはめ値は約 1.13–1.17）。

### 1.5 電荷表

条件「OπO が中性」「電子 6O+6π の電荷が −1」から一意に O = +1/6、π = −1/3。

| 粒子 | 構成 | OπO + 余り | 電荷 |
|---|---|---|---|
| u | 4O | — | +2/3 |
| d | 1π | — | −1/3 |
| 陽子 uud | 8O + π | 1 OπO + **6O** | +1 |
| 中性子 udd | 4O + 2π | **2 OπO** | 0 |
| 電子 | 6O + 6π | 3 OπO + 3π | −1 |
| 水素 | 14O + 7π | **7 OπO** | 0 |

### 1.6 リングと軸 = S³ の等分の二つの芯

スピンの群 SU(2) = S³ はクリフォード・トーラスで合同な二つの中身の詰まったトーラスに等分される。二つの芯を 3 次元へ立体射影すると、一方は円（リング O）、他方は無限遠を通る直線 = z 軸（軸 π）。**「直線なのに円」**は、この芯と、トーラス上の測地線（切り開くと直線、丸めると円を描く）の二重の意味で正確である。

### 1.7 近づくが戻らない — 黄金比

トーラス上の直線は傾きが無理数なら閉じず、どの位置にも限りなく近づく（クロネッカー）。有理数で最も近似されにくいのは φ（フルヴィッツ）。双極との関係:

    x · (1/x) = 1  かつ  x − 1/x = 1  ⟹  x = φ

傾き 1 の閉じる軌道（ホップ・ファイバー、4π で戻るスピノル）と、閉じない φ の軌道が双極の対をなす。

### 1.8 記法 P, E と 1 ⊕ 3 ⊕ 5

    P = xX + yY + zZ + rR + iI + jJ
    E = (xX + yY + zZ) ⊗ (ωx, ωy, ωz) + rR + iI + jJ

空間を双極で分けると 3 平面（XY・YZ・ZX）で 8 = 2³ 空間。これは 3 次元幾何代数 Cl(3) の成分 1 + 3 + 3 + 1 と一致し、3 階の要素 XYZ は 2 乗して −1（F → B の 90° 変換を担う）。

    r⊗ω = (r·ω) ⊕ (ω×r) ⊕ (対称・トレースなし)
          1 成分     3 成分     5 成分
          スカラー   回転       歪み

伝わる横波として残る自由度は、3 成分がヘリシティ ±1（光）、5 成分が ±2（重力波）。

## 2. 構成として成立、原理は未確定 [B] — 到達の手法

### 2.1 電子の g 因子 — 歪みゼロとの同時解

構成: リング O（電荷 +1）と軸 π（電荷 −2）を**逆回転**（同じ向きでは電流が打ち消し合い場が作れない）。線は太さがないとエネルギーを持てないので有限の太さを持つ。閉じ込めの場（電荷 0）がスピンを担う。

#### 2.1.1 経過

| 段階 | 結果 |
|---|---|
| R³、リング＋軸のみ | g = 3(A+2B)/(B−A)。g = 2 に決してならない |
| R³、閉じ込めがスピンを担う | g = 2 は可能。閉じ込めの循環半径 4.5R を要する（未導出）。A = B でリングと軸の循環半径が一致＝**重なり** |
| 太さ | 4.5 は太さから出ない（太さは ln でエネルギーにだけ入る）。代わりに太さが決まる: ln(8R/a) = π/(9α) |
| **S³** | 全成分が同じ半径 ρ を共有し、**ρ は g から消える**。g は純粋な数 |
| S³、クリフォード（η = 45°）、配分 1/3 | g ∈ {−2, −6, ±9, 3/2, 1, 3}、+2 なし |
| S³、スピン = J_R、配分 1/3 | g = 2 は位相三等分（60°, 120°）で成立、エネルギー三等分（正四面体角）では 9/5 |
| **S³、配分を自由、歪みゼロを課す** | **解は一意**（§2.1.3） |

ホップ写像で η はスピン球面の緯度 θ = 2η に移る。リングの芯 = 北極、軸の芯 = 南極。

#### 2.1.2 歪みゼロの条件

スピン 1/2 の状態は密度行列 ρ = ½(1 + n·σ) しかとれず、スピン球面上で ℓ = 0（1）と ℓ = 1（3）のみを持ち、**ℓ = 2（5）を持てない**。電子に四重極モーメントがない理由であり、大きさに依らず成り立つ。§1.8 の 1 ⊕ 3 ⊕ 5 で「5 がゼロ」は、外から見た多重極の中身が点状のスピン 1/2 と一致することを意味する。

一般配置: リング（北極、エネルギー f_r）、軸（南極、f_a）、閉じ込めの場の双極対（f_b、cosθ = ±u）。光速運動では μ_R はエネルギー配分に依らず、

    g = 1 / [ (f_r + f_a) − f_b·u ]
    エネルギーの ℓ=2:  (f_r + f_a) + f_b·P₂(u) = 0,  P₂(u) = (3u² − 1)/2

#### 2.1.3 結果 — 一意解

    g = 2  かつ  ℓ=2 = 0   ⟹   f_b = 3/4,  f_r + f_a = 1/4,  cosθ = ±1/3

- 閉じ込めの場の位置は**正四面体角 109.47° と 70.53°**。
- リング＋軸（O と π の部分）が**ちょうど 1/4** — 「OπO は電子の 1/4」が仮定でなく解として出る。
- 1/3 配分の仮定も位相三等分も使っていない。スピン 1/2 と g = 2 の二条件だけで決まる。
- 1/3 配分に固定したときの正四面体角（g = 9/5）の失敗は、配分の固定が原因だった。配分を自由にすると正四面体角のまま g = 2 が成立する。
- **前段の位相三等分解（60°, 120°）はエネルギーの ℓ=2 が 5/8 でスピン 1/2 に不適合。除外する**（§3）。

#### 2.1.4 到達の手法

1. **電荷の四重極**: リング +1・軸 −2 が両極にある限り電荷の ℓ=2 は −1。ゼロにするには総電荷 −1 をリング＋軸 −1/4、閉じ込めの場 −3/4（エネルギーと同比）に配る必要があり、O = +1/6・π = −1/3 の電荷表と衝突する。手法: (a) 閉じ込めの場に電荷を持たせる構成で g と歪みゼロが保たれるかを解く、(b) 電荷表を保ったまま、極への集中を緩めて電荷分布を広げる。
2. **高次の階数**: スピン 1/2 は ℓ ≥ 2 をすべて持てない。現解は ℓ = 4 が 7/27 で残る。手法: 極・円への集中をやめ、球面上の滑らかな (1 + cosθ) 型分布に置き換え、正四面体角と 1/4 がその分布の中でどう表れるかを確かめる。
3. **尺度**: 多重極は点状と ℓ = 2 まで一致したが ρ は残る。手法: 1 と 2 が満たされた分布で、ρ を内部の位相の尺度として読む定式化を立てる。
4. 精密値 2.00231930… の 0.00232（主要部 α/2π）は 1–3 の後に扱う。

### 2.2 質量 — 中性子と陽子の差

    Δ = m_n − m_p − m_e = 0.78233 MeV = 1.53099 m_e = 18.372 単位（m_e/12）

陽子の余りの電荷を陽子の大きさに閉じ込める自己エネルギー（rms 0.8409 fm）は 0.80（一様球）/ 0.84（ガウス）/ 0.93 MeV（指数）で Δ と同規模だが、陽子を重くする向き（差を縮める側）に働く。主流の分解（格子 QCD、要原典確認）は概ね +2.5（強い力）−1.0（電荷の拘束）−0.511（電子）。

**到達の手法**: 拘束項（−1.0）は余りの 6O の拘束収縮として立てられる。未導出の本体は u → d（4O → π）の置換で増える約 2.5 MeV。O と π に別の重さを持たせる規則を決め、この置換エネルギーを出す。

### 2.3 成長と吸収の限界

「増加に境界が反発し、拘束収縮が吸収する」は R ∝ A^β、β < 1/3 と書ける。原子核は全体で β = 0.28、A ≥ 58 で 0.31（密度頭打ち）。白色矮星では吸収が続き（R ∝ M^(−1/3)）、チャンドラセカール限界で崩壊、電子が陽子に押し込まれる閾値は 0.782 MeV。

**到達の手法**: OπO の拘束収縮から β と吸収の限界条件を出し、原子核（0.31）・白色矮星（−1/3）と比べる。限界の先の転移を「陽子と電子が一つになる飽和」に置く。

### 2.4 残る尺度の問題

S³ で g から半径は消え、§2.1.3 で多重極も ℓ = 2 まで点状と一致したが、ρ そのものは未決定。スピン ħ/2 に合わせると構造は 10⁻¹³ m 程度で、電子の大きさの実験上限（< 10⁻²⁰ m）と隔たる。

**到達の手法**: §2.1.4 手法 3 により、ρ を空間的な大きさでなく内部の位相の尺度として読む定式化を立て、g が保たれるかを確認する。

## 4. 記法 P, E を式として立てるための要件

1. R, I, J の定義（平面＝回転か、別の自由度か）。I は電流 I と記号が重なるため変更を推奨。
2. 次元の統一（xX は長さ、r⊗ω は速度）。
3. 場としての方程式（空間各点での変化とそれを決める式）。既存の対照は時空代数でのマクスウェル方程式 ∇F = J（Hestenes、要原典確認）。TTT が加える部分は双極・2T・位相三等分という制約。
