## 2. 構成の鎖

### S1. 0 → 2点

公理 Z による。水準 **D**。

### S2. 2点 → 1線

2点は一意に直線を決める。これを**軸**と呼ぶ。水準 **A**（初等幾何）。

### S3. 軸を回す → 3本 または 4本 または 6本

原点を通る直線を立方体の回転群 $O$（位数 24）で回すとき、軌道の大きさは軌道・固定化群定理により $|O| = 24$ の約数に限られる。実際に現れるのは三つである。

| 直線 | 本数 | 名称 | それを固定する回転の位数 |
|---|---|---|---|
| $(1,0,0)$ 型 | **3** | 座標軸 | **4**（90°） |
| $(1,1,1)$ 型 | **4** | 体対角線 | **3**（120°） |
| $(1,1,0)$ 型 | 6 | 面対角線 | 2（180°） |

$3\times8 = 4\times6 = 6\times4 = 24$（軌道の大きさ × 固定化群の位数）。軸の総数 $3+4+6=13$、群の元の数 $1 + 3\!\cdot\!3 + 4\!\cdot\!2 + 6\!\cdot\!1 = 24$。

水準 **A**（軌道・固定化群定理、Lagrange）。

> **三と四の交差**：3本の軸は4回対称を持ち、4本の軸は3回対称を持つ。本数と位数が入れ替わる。したがって「3と4のどちらが基本か」という問いは成立しない。理論の名称が二つを並置しているのは、幾何的に正しい。

**参考（点を数えた場合）**：同じ群で点の軌道は $(1,0,0)\to 6$（正八面体）、$(1,1,1)\to 8$（立方体の頂点 ＝ **8象限**）、$(1,1,0)\to 12$（立方八面体）。線は 3, 4, 6、点は 6, 8, 12。

### S4. 4個への位数3の作用 → 1固定 + 3巡回

4個の集合への位数3の作用は、**必ず1個を固定し3個を巡回する**。他の分かれ方は存在しない（$S_4$ の位数3の元はすべて3巡回であるため）。

実例：$(1,1,-1)$ を軸とする120°回転
$$R=\begin{pmatrix}0&0&-1\\1&0&0\\0&-1&0\end{pmatrix},\qquad \det R = 1,\quad \operatorname{tr} R = 0 \Rightarrow \theta = 120°,\quad R^3 = I$$
は体対角線 $(1,1,-1)$ を固定し、他の3本 $(1,1,1)\to(1,-1,1)\to(-1,1,1)\to(1,1,1)$ を巡回する。

水準 **A**（$S_4$ の共役類）。

> **帰結**：「境界内の構成は3つ、4つ目はマスとの境界」は**置いた仮定ではなく群論の帰結**である。定義が一つ減る。

### S5. 3巡回の点 + 軸上の1点 → 正四面体

$R$ による $e_1$ の軌道 $\{e_1,\ e_2,\ -e_3\}$ に、軸上の点 $(1,1,-1)$ を加えた4点は、**6辺すべてが $\sqrt2$ の正四面体**をなす。水準 **A**（計算、`ttt_core_verify.py` §5）。

### S6. 4点 → 外接球ただ1つ ＝ 1

同一平面上にない4点は球を一意に決める。上の正四面体では

$$\text{中心} = \left(\tfrac12, \tfrac12, -\tfrac12\right) = \tfrac{(1,1,-1)}{2},\qquad R = \tfrac{\sqrt3}{2} = \tfrac{a\sqrt6}{4}$$

**中心は軸の上にある。** 水準 **A**（初等幾何＋計算）。

> **「点3と線1が球となって1になる」**。単位 1 はここで定義される。

### S7. 正四面体は $R/r = 3$

$$\frac{R}{r} = \frac{a\sqrt6/4}{a/(2\sqrt6)} = 3$$

プラトン立体でこの比が整数になるのは**正四面体だけ**である。

| 立体 | $R/r$ |
|---|---|
| **正四面体** | **3**（厳密） |
| 立方体 | $\sqrt3 = 1.7320508$ |
| 正八面体 | $\sqrt3 = 1.7320508$ |
| 正十二面体 | $1.2584086$ |
| 正二十面体 | $1.2584086$ |

水準 **A**（計算）。

## 3. この核が出力する数

$$3,\quad 4,\quad 6,\quad 7,\quad 8,\quad 12,\qquad \text{およびスケール比}\ 3$$

- **3, 4, 6** — 線の軌道（座標軸／体対角線／面対角線）
- **6, 8, 12** — 点の軌道（正八面体／立方体の頂点＝8象限／立方八面体）
- **7** — 正四面体の回転群（位数12）の軸の数：3本の2回軸 ＋ 4本の3回軸。$1 + 3 + 4\!\cdot\!2 = 12$ で閉じる。$7 = 3 + 4$
- **12** — 正四面体の回転群の位数 $|A_4|$
- **スケール比 3** — S7

> **注意**：この 7 は `PROOF_STATUS.md` の P7（$V(n)=n+2$、$5+2=7$）**とは別の7**である。あちらは多面体の数、こちらは軸の数。P7 の判定（D + A、$\{5,6,7\}$ の最大値であって導出ではない）は変わらない。

## 4. 記号系との対応

$O\pi O$ を「1本の体対角線 ＝ 両端の2つの球 $+$ その軸まわりの回転 $\pi$」と同定すると、既存の記号系が数として整合する。

| 記号系の言明 | 幾何 |
|---|---|
| 4 $O\pi O$ で1テトラ | 4本の体対角線 |
| 8つの $O$ | 立方体の8隅 ＝ **8象限** |
| 4つの $\pi$ | 4本の回転軸 |
| 記号12個 $\times\,0.25 = 3$ | 「4 $O\pi O$ は3になる」 |
| 4 $OO\pi O$ ＝ 16記号 $= 4$ | 追加の4つの $O$ ＝ テトラの4面（境界） |
| 双極 | $T^+$ と $T^-$（立方体に内接する2つの正四面体、星型八面体） |
| 「2個の球はつながった境界で1つしかない」 | 1本の対角線 |

水準 **D**（同定であって定理ではない）。ただし全項目が矛盾なく数として合う。

## 5. この核が言わないこと

1. **次元を持つ量を一つも出さない。** 長さも質量もエネルギーも出力しない
2. **個数の増殖則を含まない。** S7 の 3 は**大きさの比**であって個数ではない
3. **物理量の予言を含まない**

> **確定した予言：0件。**
>
> 全段が定理であるということは、**どこも間違いようがない**ということである。間違いようがないものは、まだ物理ではない。本書の核は数学として硬く、経験的には空である。この二つは同じ事実の二つの言い方である。

## 7. 検定にかけうる唯一の主張（候補）

> **H-L（長さの塔）**：ある段の内接球が次の段の外接球であるなら、段ごとの大きさは厳密に $3^n$ になる。

- **較正**：長さのアンカーを1つ外から与える（S7 は比のみを与える）
- **反証条件**：本理論が「入れ子である」と主張する系において、二つの特徴長の比が 3 の冪から外れたとき棄却
- **注意**：$R/r=3$ は正四面体固有であるため、他の多面体で入れ子を組むとこの主張は成立しない。三と四の選択がそのままこの比を決めている

これが現時点で唯一、**外れうる**主張である。
