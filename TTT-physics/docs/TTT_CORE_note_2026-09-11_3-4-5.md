## 1. 3-4-5 と 37 — 一本の恒等式

$$3\cdot4+5^2 \;=\; 3^2+3\cdot4+4^2 \;=\; 4^3-3^3 \;=\; 37$$

* 37 に 5 は不要。核の出力 (3, 4) だけで書ける。
* 余弦定理 $25-24\cos\theta$: θ=0°,60°,90°,120°,180° で **1, 13, 25, 37, 49**。
  25（3²+4²）は 90° の段、37 はその一つ上の 120° の段。段差 12 = 交差項 3×4。
* **正四面体の 12 本**（有向辺 12 = FCC 最近接 12 = 接吻数、T⁺ と T⁻ で同一集合）。
  6 辺 15 対 = 直交 3 対 + 60° 12 対。
  4 回軸に垂直な面は正方格子 → $|3u+4v|^2/2=25$。
  3 回軸（OπO 軸）に垂直な面は三角格子 → 37。
  12 本の線分は各座標軸に 4 本ずつ直交（12=3×4 は接続関係として本物）。
* 体対角線方向から見た 4³ 立方体の見える 3 面 = 六角形 37 マス、奥に 3³=27。
  中心六角数 1, 7, 19, **37**, 61, **91** —— 殻 91 も同じ列。
* 核が本来もつピタゴラスは **1+2=3**（辺²・面対角線²・体対角線²）であって 3-4-5 ではない。

**警告**: 係数 (3,4) は格子が選ばない（任意の (a,b)、任意のピタゴラス数で $ab+c^2=a^2+ab+b^2$）。
軸の**本数**を**歩数**として使う一歩は「長さの錯覚」と同じ場所にある。
交差項の 12 と辺の 12 は同じ数・違う理由。

## 2. 162 / 125 / 91 / 37 / 54 — 立方版 3-4-5 が束ねる

$$3^3+4^3+5^3=6^3=216$$

連続 3 立方の和が立方になるのは 3 始まりのこの組**だけ**（10⁵ まで探索）。

| 数 | 立方で書くと | 由来 |
|---|---|---|
| 216 | $3^3+4^3+5^3$ | 6³ 格子 |
| 91 | $6^3-5^3=3^3+4^3$ | 殻 |
| 37 | $4^3-3^3$ | あふれ (k=5) |
| 54 | $91-37=2\cdot3^3$ | R(4) |
| 128 | $91+37=2\cdot4^3$ | （9/9 の 2⁷） |
| 125 | $216-91$ | 5³ 格子 |
| **162** | $5^3+4^3-3^3=6^3-2\cdot3^3=216-54$ | R(5) |

* $162-125=37$ はそのまま $4^3-3^3$。
* 二つの数列: 球 $R(k)=2\cdot3^{k-1}$ = 2,6,18,54,**162**／双錘 $B(k)=3^{k-1}$ = 1,3,9,27,**81**／格子 $k^3$ = …,64,**125**。
  k=5 で 81 < 125 < 162、分割 **44 : 37**。$2\cdot3^4+3^3=5^3+4^3=189=7\cdot27$。
* 副産物 $81-64=17$ は 9/7 の 17 とは出どころが別。事前登録なし。傍証にしない。

## 4. S8 の試み — 核から 3-4-5 を強制できるか（結果: 未達）

**根本の障害: 核に 5 がない。** 出力は 3, 4, 6, 7, 8, 12（5 は 8−3 か 12−7 でしか作れず後付け）。

最良候補 S8 案:
> S4 の「1 固定 + 3 巡回」を体積に写し、「固定 1 つの立方 = 巡回 3 つの**連続**立方の和」と置く。

→ 解は $n=6$ ただ一つ（2000 まで探索）、3,4,5,6 がすべて出る。
次元 d で「d 個の連続 d 乗和が d 乗」は **d=2 → 5（3-4-5）、d=3 → 6（3-4-5-6）** のみ。d=1,4,5,6 は解なし。
3 始まりが両方で共通だが d=4 で切れるので一般則ではない。

**判定**: 置いた仮定は「連続」と「体積」の 2 つで、導きたいものと同じ重さ。**埋まっていない**。
「連続」を外すと (1,6,8,9), (3,10,18,19), (7,14,17,20)… が並び、(3,4,5,6) は単に最小解。

埋めるのに必要なもの: $R$（120° 回転、$R^3=I$）が 3 本を**巡回させる**性質から「巡回 = 1 段拡大」を出す規則。
現状 $R$ は入れ替えるだけで大きくしない（9/7 警告 (a)「群は構造を与えるが増殖は与えない」と同じ壁）。
