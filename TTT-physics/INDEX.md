## 🧩 2. 公理系について — 二つの異なるレベルがある

このリポジトリには、性質の異なる二つの公理的出発点が混在している。混同しないこと。

### 2.1 機械検証済みの核（`TTT_CORE.md`）

唯一の仮定は**公理Z**（「0は双極で2になる」、水準D）。以降のS1–S7はすべて定理または群論的に強制される帰結（水準A、`ttt_core_verify.py`で検証可能）。出力は $3,4,6,7,8,12$ とスケール比3のみで、次元を持つ量は一切出さない。

### 2.2 本ファイル系列が使う拡張仮定（P1–P5、未検定）

`higgs_mass_derivation.md` 等が用いる以下の公理は、TTT_COREの外側にある独自の追加仮定であり、機械検証を経ていない。

1. **P1（6次元空間構造）**: $S=\mathbb{R}_r^3\times\mathbb{R}_u^3$
2. **P2（自己相似条件と黄金比）**: $x=1+1/x \Rightarrow x=\varphi$
3. **P3（生成階層性）**: 双極→線分→三角形→正四面体→9点オクタ
4. **P4（有限反射群）**: $A_3, B_3, H_3$
5. **P5（6次元不変量）**: $I=f(\|\mathbf r\|,\|\mathbf u\|,\mathbf r\cdot\mathbf u)$

**既知の問題**：P2の黄金比とTTT_COREのS7（正四面体のみが整数比$R/r=3$を持つ）は、異なる多面体族（$\varphi$は正十二面体・正二十面体族、$3$は正四面体族）に基づいており、両立の可否は未決（`TTT-mathematics/golden_ratio_from_6d_equation.md`、C判定）。また、n角双錐の頂点数公式 $V(n)=n+2$ からの「7」の導出は、`PROOF_STATUS.md` P7項目でD+A判定（$\{5,6,7\}$のうちの最大値を選んだ取り決めであって、導出ではない）。

正多面体5種・離散代数基底（$B_{\text{vol}}=5^3=125$、$B_{\text{trans}}=2^7=128$、$V_{\text{eff}}=4+12/20=4.6$）の定義自体はここでは変更していないが、これらから物理定数が一意に出るという主張（2.3節以降）はF/C判定であることに注意。

## 📈 4. 実験的予言と反証条件（候補・未検定）

以下はTTT理論から導かれるとされる実験的予言の**候補**である。3節の判定の通り、根拠となる式自体がF/C判定であるため、これらは検証すべき仮説であって確立された予言ではない。

### 4.1 提案されている共鳴

| 名称 | 質量 | 由来 |
| :--- | :---: | :--- |
| $H_1^*$ | 2197 GeV | $13^3$ |
| $H_2^*$ | 2744 GeV | $14^3$ |
| $H_3^*$ | 3375 GeV | $15^3$ |

立方数の列を直接GeVと読む換算則（O1）が未決のため、この対応自体がまだ検定にかけられる形になっていない（`experimental_predictions.md`、C判定）。

### 4.2 反証条件の草案

- [ ] ヒッグス質量が $125.25 \pm 0.03$ GeV から外れた場合 — ただし125.25自体が較正点であるため、この条件は実質的に無内容（既知の値からの乖離を測っているに過ぎない）
- [ ] FCC-hh で $2197\pm20$ GeV 領域に $J^P=0^+$ 共鳴が $5\sigma$ で排除された場合
- [ ] $1/\alpha(0)$ の10桁目が $137.03599908$ から大きく外れた場合

**重要な訂正**：「自由パラメータを持たないため、これらの反証条件は理論全体を即座に棄却する」という旧版の記述は撤回する。実際には最低9個の手置き数が存在するため、個々の反証条件が破れても、手置き数の再調整で局所的に「救済」できてしまう。これは`falsifiability_criteria.md`（C判定）の指摘そのものであり、真に外側にある反証条件を再設計することが今後の課題である。

## 💻 5. 検証スクリプトについて

`docs/TTT_CORE.md` に付属する `ttt_core_verify.py` は、S1–S7の幾何の鎖をassertで機械検証する、本リポジトリで**唯一**A判定のスクリプトである。

一方、本ファイル旧版に含まれていた「Python（Decimal）による一括検証スクリプト」は、上記のF/C判定の式（$m_h$、$1/\alpha$、$R$、$\Delta m_{np}$）を単に計算して観測値と並べて表示するだけのもので、**独立した検証ではない**（式そのものの妥当性は問わず、算術が合っているかを確認するだけ）。誤解を避けるため、このセクションからは削除した。同等のコードが必要な場合は `TTT-physics/verify_alpha_v4.py`（監査・未確認）を参照。
