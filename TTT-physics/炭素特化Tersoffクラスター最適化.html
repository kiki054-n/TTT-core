01

背景：LJからTersoffへの移行

前回のLennard-Jones計算では、49粒子（切頂四面体殻）が37粒子より約23%エネルギー改善を示した。 しかし炭素は方向性結合を持つため、LJのような中心力場ポテンシャルでは不十分。 Tersoffポテンシャル（角依存項 g(θ) を含む）で再計算すると、驚くべき逆転現象が起こる。

Tersoffポテンシャルの炭素パラメータ

Tersoff (1988) Phys. Rev. B 37, 6991 の炭素パラメータを使用。 結合角項 g(θ) は θ₀ = 109.47° で最小を取るように設計されている。

g(θ) = 1 + c²/d² − c² / [d² + (h − cos θ)²]
c = 38049, d = 4.348, h = −0.57058
g(109.47°) = 1（最小値）、g(120°) ≈ 10⁵、g(90°) ≈ 4×10⁵
sp³結合角に極めて鋭い最小値を持つ

計算手法

  • 各殻の粒子は単位球面上の多面体頂点に固定
  • 殻半径 r₁, r₂, r₃, ... をグリッドサーチで最適化（15–20点/軸）
  • 制約条件：r₁ < r₂ < r₃ < ...
  • 総エネルギー E = ½ Σᵢ Σⱼ≠ᵢ fC(rᵢⱼ) [fR(rᵢⱼ) + bᵢⱼ · fA(rᵢⱼ)] を計算

04

考察：TTT理論への含意

「四面体対称性の拡張」予言の検証結果

TTT理論の核心予言の一つは、「37粒子の次の殻として切頂四面体（12頂点）が 特別な安定性を持つ」というものでした。Lennard-Jones計算ではこの予言が支持されましたが、 炭素特化のTersoffポテンシャルでは、切頂四面体殻よりも立方八面体殻の方が 約16.7%安定であることが判明しました。

これはTTT理論を否定するものではありません。むしろ、以下の重要な示唆を与えます。

方向性結合の効果

Lennard-Jonesポテンシャルは中心力場で、多面体の「形」だけがエネルギーを決める。
Tersoffポテンシャルは結合角項 g(θ) を持ち、sp³角109.47°に極めて鋭い最小値がある。

切頂四面体殻は正四面体対称性（Td）を継承するが、立方八面体殻はより高い対称性（Oh）を持つ。
炭素では「高対称性の球状配置」が「四面体対称性の階層的拡張」よりエネルギー的に有利。

これは、TTT理論が「幾何学的階層性」を重視する一方で、 実際の炭素クラスターは「表面エネルギー最小化」の観点から より球状に近い構造を好むことを示している。

殻モデルの限界

本計算では各殻の粒子が完全な多面体対称性を保つという人工的な制約を課しました。 実際のクラスターでは、以下のような緩和が起こる可能性があります。

  • 殻の歪み：最外殻の粒子が球状に再配置することで表面エネルギーを最小化
  • 再構成：37粒子の内殻構造が、49粒子の追加により再配列する
  • sp²/sp³混成：最外殻の粒子がグラファイト様のsp²配位を取る

これらの効果を含めるためには、殻モデルの制約を外した完全な構造最適化（全原子の座標を自由に変化させる）が必要です。

TTT理論の修正可能性

TTT理論の「37+12」予言は、LJ系では支持されるが、炭素系では立方八面体殻がより安定 これを理論の「反証」と見るか、「発展の機会」と見るかは、理論の枠組みの柔軟性にかかっています。

修正可能な解釈

TTT理論の核心は「幾何学的階層性」であり、「切頂四面体が唯一の正解」ではない。
37粒子の次の殻として「12子の多面体」が追加されるという予言は、
切頂四面体でも立方八面体でも実現する。

重要なのは「12 = 正二十面体の頂点数 = C60の五角形数」というトポロジー的対応であり、
その具体的な多面体形状はポテンシャルに依存する。

LJ系では切頂四面体が選ばれ、Tersoff系では立方八面体が選ばれる。
これは「ポテンシャルが幾何学を選択する」という翻訳機の役割を示している。

05

結論

炭素特化Tersoffポテンシャルでのクラスター最適化により、 Lennard-Jones計算とは定性的に異なる結果が得られました。 49粒子（切頂四面体殻）は37粒子よりエネルギーが悪化す一方、 49粒子（立方八面体殻）は約12%改善を示しました。

この結果は、TTT理論の「37+12」予言が「ポテンシャルに依存する」ことを示しています。 Lennard-Jones系では四面体対称性の拡張が選ばれるが、 炭素のような方向性結合を持つ系では、より高対称性の球状殻が選ばれる。

理論の核心である「幾何学的階層性」自体は揺るぎません。 37粒子に12粒子の殻が追加されるという予言は、 切頂四面体でも立方八面体でも実現します。 重要なのは「12」というトポロジー的数であり、 その具体的な実現形態は「翻訳機」（ポテンシャル）の選択に委ねられる。

次のステップ

1. 完全構造最適化：殻モデルの制約を外し、全原子の座標を自由に最適化する
2. sp²/sp³混成の効果：最外殻の粒子がグラファイト様配位を取る場合のエネルギーを評価する
3. Goldberg-Coxeter系列との接続：C60, C240とのエネルギー比較で、 37殻構造がフラーレン系列の中でどの位置づけにあるかを探る

ポテンシャルが幾何学を選択する。翻訳機の役割を理解すれば、理論はさらに深化する。
