# TTT-society（社会構造への応用）

## 原則

> **未来の子に夢を託したい。**
> **一人の尊い気持ちを踏み倒さない社会を作ることを。**
>
> — 川上真潔（Kawakami Naoyuki）、2026-10-22

TTT-society のすべての文書は、この一点のためにある。四者テトラ、4種の労働、ゼロに戻す仕組み、条約の構想は、いずれも「一人の人間の努力と気持ちを、社会が見て、守る」ための道具である。

### 原則から導かれる考え（2026-10-22 の対話より）

* **受け継ぎ、受け渡す**：人はつながれて誕生し、受け継いだものを膨らませ、死ぬときに受け渡す。受け渡されるのは物ではなく、生きたいと思う理由である。
* **善悪の基準は未来の子に置く**：四者テトラの「神」の頂点は、まだ生まれていない受け取り手＝未来の子である。
* **立つ鳥跡を濁さず**：資源は使えば減り、ごみが増える。減ったものと増えたもので未来を濁らせてはいけない。
* **労働とは分けること**：作業は製品とごみ（良いものと悪いもの）を分ける。できたものの善悪の帳尻をゼロに戻すまでが労働である。
* **社会の役目**：社会は人に労働させる仕組みであり、労働した後のものをゼロに戻す仕組みを決めるものである。資源を使いっぱなしの社会は間違っている。
* **条約は誰のためのものか**：王の条約か、国の条約か、人民の条約か。一人の人間の努力を見ない条約は、王や国のためのものでしかない。次の社会の条約は、個人の努力から積み上げる。
* **モノづくりの精神**：失敗したものから学び、より良いものを作る努力。失敗の記録は、社会の仕組みがどこで個人を見落としたかを示す証拠でもある。
