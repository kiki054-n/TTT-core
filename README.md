# TTT-core

TTT-core（Tri-Tetra Theory 統合ハブ・根のリポジトリ）

TTT理論は、単一の公理（公理Z）から出発する幾何学的な構成の連鎖（TTT-mathematics）と、その先に物理定数が導けるかどうかを検定する場（TTT-physics）から成ります。社会構造（TTT-society）と意識モデル（TTT-consciousness）は、物理側の基盤が固まったあとに初めて意味を持つ推論的な応用として位置づけており、現時点では独立した哲学的応用にとどまります。

このリポジトリ自身は理論の「入口」であり、以下の4領域への案内役を担います。

## 構成

```
TTT-core/              ← 統合ハブ（哲学・公理・全体像、このリポジトリ）
├── TTT-mathematics/    ← 純粋数学（証明の巣）
├── TTT-physics/        ← 物理理論（検証の場）
├── TTT-society/        ← 社会構造（応用の域）
└── TTT-consciousness/  ← 意識・観測者（推論の域）
```

（4領域は独立リポジトリではなく、このTTT-core内のサブディレクトリとして管理しています）

## 各領域の現状

| 領域 | 役割 | 現状 |
| --- | --- | --- |
| [TTT-mathematics](./TTT-mathematics/) | 物理単位を一切使わない、公理からの純粋数学的定理導出 | 7本のドキュメントで公理・定理を展開中 |
| [TTT-physics](./TTT-physics/) | 唯一、実験と対峙するリポジトリ。理論の反証可能性を担う | 核となる構成の鎖は [TTT_CORE.md](./TTT-physics/docs/TTT_CORE.md) に、判定の全記録は [STATUS.md](./STATUS.md) にまとめ済み |
| [TTT-society](./TTT-society/) | TTT-mathematicsの幾何学的構造からの推論的応用（実験的検証可能性なし） | 未着手（方針のみ） |
| [TTT-consciousness](./TTT-consciousness/) | 量子力学の測定問題への幾何学的解釈（哲学的・現象学的推論） | 未着手（方針のみ） |

TTT-societyとTTT-consciousnessの主張は、TTT-physicsのような実験的検証可能性を持ちません。これにより、物理領域の「科学性」が両者の推論的な主張によって汚染されないよう明確に区別しています。

## 核となる結果 — 何が確定していて、何がまだ確定していないか

TTT理論のうち、**機械検証を通っているのはTTT-mathematicsの構成の鎖だけ**です。唯一の仮定（公理Z：「0 は双極で 2 になる」）から、以降はすべて定理または群論的に強制される帰結として、次の数が導かれます。

$$3,\quad 4,\quad 6,\quad 7,\quad 8,\quad 12,\qquad \text{正四面体の外接球/内接球比} = 3$$

これは長さ・質量・エネルギーのような次元を持つ量を一つも含まない、純粋に幾何学的な結果です。**この核から確定した物理的予言は0件です。** 全ステップが定理であるということは、どこも間違いようがないということであり、間違いようがないものはまだ物理ではありません。詳細と機械検証スクリプトは [TTT_CORE.md](./TTT-physics/docs/TTT_CORE.md) を参照してください。

微細構造定数の逆数 $1/\alpha \approx 137.036$ や陽子・電子質量比 $\approx 1836$ のような物理定数への対応づけは、この核の**外側**にある個別の仮説であり、確立された結果ではありません。これらを含む主張の現在の判定（反証済み・仮説／未検定・未判定）は [STATUS.md](./STATUS.md) に一覧化しています。中には監査の結果、的中していないことが確認済みのもの（例：陽子・電子質量比の候補式は実測値との差が約477万σ）も含まれます。判定を後から静かに書き換えないという方針（[PROOF_STATUS.md](./TTT-physics/docs/PROOF_STATUS.md) §27）のもと、反証済みの記録もそのまま保存しています。

## 使い方 - 間違いを育てる

TTT理論は辞書です。使い方の手順は `reading-the-wind` にあります。

> **OOπの表面を押せば、見えない裏面の変形が予想される。乖離の中に、次の変数が眠っている。**

詳細な運用手順、三列比較テンプレート、検証事例は以下を参照してください。

**→ [USAGE.md - TTT理論の使い方: 間違いを育てるフレームワーク](./USAGE.md)**

**→ [reading-the-wind: 見えないものを読む理論](https://github.com/kiki054-n/reading-the-wind)** - 気象・司法・砂川事件・日独比較の検証ログ

### Quick Start: 4ステップ

1.  **表面を記録:** 今見えている事実 (rR)
2.  **裏面を予想:** 6変数から支配変数を1つだけ選んで断言する (例: zZ≒0)
3.  **三列比較:** TTT予報 / データ予報 / 現実 を並べる
4.  **乖離を分類:** 量的・位置的・時間的・質的 → 第7項 (hH,eE,nN...)を発見

外れた記録はIssueで共有してください。

## 公理系（概要）

トリテトラ理論の基本公理: ΣV=0, JIK=-1, 0,0 → 1,-1

```
0,0（双極的無）→ 公理
└── TTT-mathematics（数学的必然）
    ├── 正多面体5種の証明
    ├── 黄金比の一意性
    └── 6次元解空間の構造
        └── TTT-physics（検証の場）
        │   ├── 核（S1–S7、機械検証済み）: 3, 4, 6, 7, 8, 12・比3
        │   └── 物理定数との対応（1/α, m_p/m_e, m_H 等）: 検定中／一部反証済み → STATUS.md
        ├── TTT-society（社会的推論・未着手）
        │   └── 四権構造の数学的根拠（構想）
        └── TTT-consciousness（意識的推論・未着手）
            └── 観測者の幾何学的位置（構想）
```

厳密な公理の記述、5領域間の関係図、命題ごとにどのリポジトリで証明されるかの全体マップ、用語統一の辞書（glossary）は今後このREADMEに追記していく予定です。
